\subsection{Quasicoherent sheaves}

\subsubsection{The category of quasicoherent sheaves}

Recall that for a ringed space $\O_X$ we have an Abelian category $\Mod_{\O_X}$ of $\O_X$-modules.
Unfortunately this category is often unwieldy, especially when $X$ is a scheme as we would like our modules to also locally look nice.
Recall the embedding $\Mod_A\inj\Mod_{\spec A}$ which maps $M\mapsto\tilde M$, whose sections on the distinguished open sets are
$$ \tilde M(\dof f) = M_f . $$

\bdefn

    If $X$ is a scheme, then an $\O_X$-module $\F$ is called a {\emphcolor quasicoherent sheaf} if for every affine $\spec A\subseteq X$,
    $\F|_{\spec A}\cong\tilde M$ for some $A$-module.
    The full subcategory of $\Mod_{\O_X}$ consisting of quasicoherent sheaves is denoted $\QCoh_X$.

\edefn

\bthrm

    To check that an $\O_X$-module $\F$ is quasicoherent, it is sufficient to check that $\F$ restricts to an $A$-module on any affine cover of $X$.

\ethrm

\bproof

    We will show that the property $\F|_{\spec A}\cong\tilde M$ satisfies the conditions of \refmath{affcomm}.
    The first condition is easier, as if $\F|_{\spec A}\cong\tilde M$, then $\F|_{\spec A_f}\cong\tilde M_f$.

    Now suppose $A=(f_1,\dots,f_n)$, $\F$ is an $\O_{\spec A}$-module such that $\F|_{\dof f_i}\cong\tilde M_i$ where $M_i$ are $A_{f_i}$-modules.
    We want to show that there is an $A$-module $M$ such that $\F\cong\tilde M$.

    Now consider the isomorphisms
    \diagram{
        &\F|_{\dof f_i\cap\dof f_j}\cr
        \tilde M_i|_{\dof f_i\cap\dof f_j}&&\tilde M_j|_{\dof f_i\cap\dof f_j}
    }{
        \diagarrow{from={1,2}, to={2,1}}
        \diagarrow{from={1,2}, to={2,3}}
    }

    By taking sections over $\dof f_i\cap\dof f_j$, this yields an isomorphism $\phi_{ij}\colon(M_i)_{f_j}\to(M_j)_{f_i}$ of $A_{f_if_j}$-modules.
    Furthermore these $\phi_{ij}$ satisfy the cocycle conditions, as is easily verified.
    Let $M_{ij}=(M_i)_{f_j}$ which we identify with $M_{ji}=(M_j)_{f_i}$ via $\phi_{ij}$.

    Now define $M$ to be such that the following sequence is exact (i.e.\ $M=\ker\gamma$):
    $$ 0 \to M \to \prod_{i=1}^n M_i \xtos\gamma \prod_{i<j}M_{ij},\qquad \gamma(m_i)_i = (m_i-m_j)_{i<j} . $$

    Now we claim that $\tilde M_{\dof f_i}\cong\tilde M_i$, i.e.\ $M_{f_i}\cong M_i$.
    Furthermore we claim that these isomorphisms fit into a commutative triangle

    \diagram{
        &M_{f_if_j}\cr
        M_{ij}&M_{ji}
    }{
        \diagarrow{from={1,2}, to={2,1}}
        \diagarrow{from={1,2}, to={2,3}}
        \diagarrow{from={2,1}, to={2,3}, text={\phi_{ij}}, y distance=.25cm}
    }

    Let us assume that $i=1$, then because localization is exact, we have that $M_{f_1}=\ker\gamma_{f_1}$.
    On the other hand the following sequence
    $$ 0 \to M_1 \xtos\beta \prod_{i=1}^n(M_i)_{f_1} \xtos{\gamma_{f_1}} \prod_{i<j}(M_{ij})_{f_1},\qquad \beta(m)=(m_i)_i $$
    is exact.
    This is because we can rewrite it as
    $$ 0 \to M_1 \to \prod_{i=1}^n(M_1)_{f_i} \to \prod_{i<j}(M_i)_{f_if_j} , $$
    which is exact.
    This gives us an isomorphism $M_1\cong M_{f_1}$ as desired.

    Now it is straightforward to prove that these isomorphisms commute with $\phi_{ij}$.
    Thus $\tilde M$ is isomorphic to the gluing of the $\tilde M_i$, but this gluing is $\F$, as desired.
    \qed

\eproof

\bexam

    Let $X=\spec k[t]$, and let $\F$ be the skyscraper sheaf supported at $[(t)]$ with group $k(t)$ and the usual $k[t]$-module structure.
    Because $k(t)$ is the field of fractions of $k[t]$, it has a canonical $k[t]_f$-module structure for all $f\in k[t]$.
    Thus $\F$ is an $\O_X$-module.

    But it is not quasicoherent: if it were then $\F$ would be isomorphic to $\tilde{\Gamma(X,\F)}=\tilde{k(t)}$.
    But this is not the case as $\F(\dof t)=0$ (since $(t)\notin\dof t$), while $k(t)_t\cong k(t)\neq0$.

    In general if $X$ is an integral scheme with function field $K(X)$, then the skyscraper sheaf $p_*K(X)$ is a non-quasicoherent $\O_X$-scheme unless $p=\eta$ is generic.
    We can restrict this to an affine subscheme containing $p$.
    Then the above argument works as well, as there is an $f\in A$ such that $p\notin\dof f$ and so $p_*K(X)(\dof f)=0$ while $\tilde{K(X)}(\dof f)=K(X)_f\cong K(X)\neq0$.
    Meanwhile if $p=\eta$ is generic then $\eta_*K(X)(\dof f)=K(X)$ for all $f\in A$ because $\eta$ lies in all of the open subsets of $X$.

\eexam

Recall that an $A$-module $M$ is {\emphcolor torsion-free} if $am=0$ implies that either $a$ is a zerodivisor or $m=0$.
If $A$ is an integral domain this is equivalent to $a=0$ or $m=0$.
An element $m\in M$ for which there exists a non-zerodivisor $a\in A$ with $am=0$ are called {\emphcolor torsion elements}.
If $M$ is an $A$-module, define $M_\tor$ to be the set of all torsion elements in $M$.
This is a submodule of $M$: if $am,bn=0$ for non-zerodivisors $a,b\in A$ then $ab\in A$ is also a non-zerodivisor and $(ab)(m+n)=0$ so that $m+n\in M_\tor$.
Clearly $M_\tor$ is also closed under scalar multiplication.

\bnote

    In the case of $A$ being an integral domain, the definition of the torsion submodule becomes
    $$ M_\tor = \set{m\in M}[am=0\hbox{ for some nonzero $a\in A$}] . $$
    Sometimes this is taken as the general definition of the torsion subset, and this is not in general a submodule of $M$ as it is not necessarily closed under addition.

    For example let $A=\bZ/\bZ_6$.
    Then $2\cdot3=0$ so they are considered torsion (in this new definition).
    But $2+3=5=-1$, which is not torsion.

    We will basically only care about torsion when $A$ is an integral domain, so we don't need to worry.

\enote

A module is {\emphcolor torsion} if all of its elements are torsion, i.e.\ $M=M_\tor$.
Over an integral domain this is equivalent to $M\otimes_AK(A)=0$.
Indeed if $M$ is torsion, let $m\in M$ then there is a nonzero $a\in A$ such that $am=0$.
Then for all nonzero $b\in A$,
$$ \frac mb = \frac{am}{ab} = 0 $$
so that $M=0$ (recall that $M\otimes_AK(A)\cong M_{(0)}$).
Conversely if $m\in M$ is torsion-free then $m/1\in M\otimes_AK(A)$ is nonzero, as it is zero only when there is a nonzero $a\in A$ for which $am=0$.

\bdefn

    If $X$ is a scheme, an $\O_X$-module is {\emphcolor torsion-free} if $\F_p$ is a torsion-free $\O_{X,p}$-module for all $p\in X$.

    If $X$ is reduced, then a quasicoherent sheaf $\F$ is {\emphcolor torsion} if its stalk at the generic point of every irreducible component is zero.

\edefn

If $X$ is integral then this is the same as saying $\F_p$ is a torsion $\O_{X,p}$-module for all $p\in X$.
Indeed if this is true then $\F_\eta$ is a torsion $\O_{X,\eta}=K(X)$-module, and since $K(X)$ is a field its only torsion modules is the zero module.
Conversely $\O_{X,\eta}$ is the field of fractions of $\O_{X,p}$ for all $p\in X$, and so $\F_\eta$ is the localization of $\F_p$, i.e.\ $\F_\eta=\F_p\otimes K(X)$.
If this is zero then $\F_p$ is torsion.

\bdefn

    If $X$ is a scheme, then its {\emphcolor distinguished affine base} is the subcategory of $\open(X)$ whose objects are the distinguished open subsets of its open affine subsets.
    Then for any $\spec A\subseteq X$ we add only the morphisms $\dof_A(f)\subseteq\dof_A(g)$.

    In other words this category contains all of $X$'s affine open subsets, and for an inclusion $\spec B\subseteq\spec B'$, we add it as a morphism only if $\spec B=\spec A_f$ and $\spec B'=\spec A_g$
    for some $\spec A\subseteq X$.

    Let us denote this category of $\open_\aff(X)$.

\edefn

Note that $\open_\aff(X)^\op$ is a cofinal subposet of $\open(X)^\op$.
If for $p\in X$ we denote by $\open_p(X)\subseteq\open(X)$ the set of neighborhoods of $p$, then $\open_{p,\aff}(X)^\op$ is cofinal in $\open(X)^\op$.

\bremark

    Note here that $\open_\aff(X)$ is not strictly a subposet of $\open(X)$, as it does not include all of its arrows.
    Nevertheless, we can still formulate what it means for it to be cofinal.

    If $\C,\D$ are two categories, a functor $F\colon\C\to\D$ is {\emphcolor final} if for all $d\in D$, the comma category $d/F$ is nonempty and {\emphcolor connected}: all objects can be
    connected by a zig-zag of morphisms.
    It can be shown that this is equivalent to precomposition with $F$ not changing colimits (i.e.\ the canonical $\colim G\circ F\to\colim G$ is an isomorphism).
    For posets the term used is {\emphcolor cofinal} as opposed to final, for historic reasons (the dual of a final functor is {\emphcolor initial}).

    If $\C,\D$ are posets then $d/F$ is the subcategory of $\C$ consisting of elements $c\in C$ such that $d\leq Fc$.
    If $\C$ is filtered then if it is non-empty it is immediately connected.
    And being nonempty just means that $F(\C)\subseteq\D$ is cofinal in the usual sense (every $d\in\D$ is bound by some $c\in\C$).

    In our case $\open_\aff(X)$ and $\open_{p,\aff}(X)$ are both cofiltered.
    If $p\in\spec A\cap\spec B$ then by \refmath[proposition]{affineinter}, $p$ is contained in a common affine neighborhood of $\spec A,\spec B$.
    And clearly $\open_{p,\aff}(X)\subseteq\open_p(X)$ is cofinal, as the affine neighborhoods of $X$ form a base.

\eremark

Because cofinal subposets don't affect colimits, for any sheaf $\F$ on $X$, its stalks can be computed relative to the distinguished affine base:
$$ \F_p \coloneqq \colim\F|_{\open_p(X)^\op} \cong \colim\F|_{\open_{p,\aff}(X)^\op} . $$

Any sheaf on $X$ defines a sheaf on the distinguished affine base.
But conversely any sheaf on $\open_\aff(X)^\op$ defines one on $X$.
The construction is by taking the sheaf $\F^b$ and defining the sheaf $\F$ on an open $U\subseteq X$ by taking the collection of compatible germs:
$$ \F(U) = \set{(f_p\in\F^b_p)_{p\in U}}[\mltext{for all $p\in U$ there is a $U_p\in\open_{p,\aff}(X)$ and a $s\in\F^b(U_p)$\cr such that $s_q=f_q$ for all $q\in U_p$}] . $$
This defines an equivalence between sheaves on $X$ and those defined on the distinguished affine base.

Suppose $\F$ is an $\O_X$-module, then for any distinguished $\spec A_f\inj\spec A$ we have the restriction map $\res\colon\Gamma(\spec A,\F)\to\Gamma(\spec A_f,\F)$.
Because the domain is an $A$-module and the codomain an $A_f$-module, by the universal property of localization this factors through $\Gamma(\spec A,\F)_f$:

\diagram{
    \Gamma(\spec A,\F)&&\Gamma(\spec A_f,\F)\cr
    &\Gamma(\spec A,\F)_f
}{
    \diagarrow{from={1,1}, to={1,3}, text=\res, y distance=.25cm}
    \diagarrow{from={1,1}, to={2,2}}
    \diagarrow{from={2,2}, to={1,3}, text=\alpha, x distance=.25cm}
}

Now $\F$ is quasicoherent iff this $\alpha$ is an isomorphism.
Indeed if $\F$ is quasicoherent, say $\F|_{\spec A}\cong\tilde M$, then this diagram fits into a larger diagram

\diagram{
    \Gamma(\spec A,\F)&&\Gamma(\spec A_f,\F)\cr
    &\Gamma(\spec A,\F)_f\cr
    M&&M_f
}{
    \diagarrow{from={1,1}, to={1,3}, text=\res, y distance=.25cm}
    \diagarrow{from={1,1}, to={2,2}}
    \diagarrow{from={2,2}, to={1,3}, text=\alpha, x distance=.25cm}
    \diagarrow{from={1,1}, to={3,1}, text=\sim, x distance=-.25cm}
    \diagarrow{from={1,3}, to={3,3}, text=\sim, x distance=.25cm}
    \diagarrow{from={3,1}, to={3,3}}
    \diagarrow{from={3,1}, to={2,2}}
    \diagarrow{from={2,2}, to={3,3}, text=\sim, x distance=.25cm}
}

Showing that $\alpha$ is an isomorphism.
On the other hand if $\alpha$ is an isomorphism then it defines an isomorphism $\Gamma(\spec A_f,\F)\to M_f$ making the rightmost triangle commute.
Thus the whole diagram above commutes, showing we have an isomorphism $\F\to\tilde M$.
We summarize this in the following lemma.

\blemm

    An $\O_X$-module $\F$ is quasicoherent iff for every distinguished $\spec A_f\inj\spec A\subseteq X$ the canonical map $\alpha$ below is an isomorphism:

    \diagram{
        \Gamma(\spec A,\F)&&\Gamma(\spec A_f,\F)\cr
        &\Gamma(\spec A,\F)_f
    }{
        \diagarrow{from={1,1}, to={1,3}, text=\res, y distance=.25cm}
        \diagarrow{from={1,1}, to={2,2}}
        \diagarrow{from={2,2}, to={1,3}, text=\alpha, x distance=.25cm}
    }

\elemm

\bdefn

    Let $(X,\O_X)$ be a ringed space.
    Then we say that $f\in\O_X(U)$ is {\emphcolor locally nilpotent} if for every point $p\in U$ there is a neighborhood $p\in V\subseteq U$ such that $f|_V$ is nilpotent
    in $\O_X(V)$.

    We define $X$'s {\emphcolor sheaf of nilpotents} to be the sheaf $\nil(X)$ whose sections are given by
    $$ \O_{\nil X}(U) = \set{f\in\O_X(U)}[\hbox{$f$ is locally nilpotent}] . $$

\edefn

Note that $f\in\O_X(U)$ is locally nilpotent iff for every $p\in U$, $f_p$ is in $\nil(\O_{X,p})$.
This is because $f\in\nil(\O_{X,p})$ iff there is a neighborhood $p\in V$ such that $f|_V\in\nil(\O_X(V))$.
This clearly shows that $\nil(X)$ is an $\O_X$-module, as $\nil(\O_{X,p})$ is an ideal for all $p$.

We can define the {\emphcolor presheaf of nilpotents} to be $\O_{\nil_\pre X}(U)=\nil\O_X(U)$.
This is in general not a sheaf, but we can see that $\nil X$ is the sheafification of $\nil_\pre X$.
We do this by showing it satisfies the universal property of sheafification.
There is an inclusion map $\nil_\pre X\inj\nil X$, which we will show is the sheafification map.

Suppose $\F$ is a sheaf and $\nil_\pre X\to\F$ is a presheaf map.
Then there is a unique extension to $\nil X\to\F$: for $f\in\nil X(U)$ there is a covering $U=\bigcup_iU_i$ such that $f|_{U_i}$ is nilpotent.
Thus it has an image in $\F(U_i)$ via $\nil_\pre X\to\F$.
These images agree on the overlaps, so we can glue them together to get $f$'s image.
This will give the same result for any covering of $U$, as if $U=\bigcup_jV_j$ is another covering then gluing the images of $f|_{U_i\cap V_j}$ will give the images of $f|_{U_i}$ and
$f|_{V_j}$.

It is easily seen that this is a map of sheaves, and uniqueness is clear.

\bnote

    $\nil(X)$ is an example of an {\emphcolor ideal sheaf} (of $X$).
    This is a subobject of $X$ in $\Mod_{\O_X}$.
    Because $\Mod_{\O_X}$ is complete and its limits are taken pointwise, by an argument identical to that in \refmath[remark]{monepiccomp} a morphism of $\O_X$-modules
    is monic iff each component is.
    Thus an ideal sheaf of $X$ is just a subsheaf $I$ whose sections are all ideals of $X$'s sections: $\O_I(U)\leq\O_X(U)$.

\enote

Recall that the tensor product of $\O_X$-modules is defined as the sheafification of the presheaf whose sections are $\F(U)\otimes_{\O_X(U)}\G(U)$.
We will show that when $\F,\G$ are quasicoherent sheaves on a scheme $X$, there is no need to sheafify.
That is, the presheaf tensor is already a sheaf.

For an affine $\spec A\subseteq X$ suppose $\Gamma(\spec A,\F)=M$ and $\Gamma(\spec A,\G)=N$.
Then define $\Gamma(\spec A,\F\otimes\G)=M\otimes_AN$.
And if $\spec A_f\inj\spec A$ is distinguished then the restriction map $\Gamma(\spec A,\F\otimes\G)\to\Gamma(\spec A_f,\F\otimes\G)$ corresponds to the localization map
$M\otimes_A N\to M_f\otimes_{A_f} N_f\cong(M\otimes_AN)_f$.
Thus $(\F\otimes\G)|_{\spec A}\cong\tilde{M\otimes_AN}$, so that $\F\otimes\G$ is a sheaf on all the open affine subsets of $X$.
In particular $\F\otimes\G$ forms a sheaf on the distinguished affine base of $X$, and thus is itself a sheaf on $X$.

\bnote

    Here we used the fact that $M_f\otimes_{A_f}N_f\cong(M\otimes_AN)_f$.
    In general we have
    $$ S^{-1}M\otimes_{S^{-1}A}S^{-1}N \cong M\otimes_AS^{-1}A\otimes_{S^{-1}A}S^{-1}N \cong M\otimes_AN\otimes_AS^{-1}A \cong S^{-1}(M\otimes_AN) . $$

\enote

\bdefn

    If $X$ is a scheme and $f\in\O_X(X)$ is a global section, let $X_f\subseteq X$ be the subset on which $f$ doesn't vanish.
    This is an open subset and as such an open subscheme of $X$.

\edefn

Note that for $f\in A$, $(\spec A)_f$ and $\spec A_f=\dof f$ are equal.
Indeed, $f$ doesn't vanish at $\p$ iff $f_\p\notin\m_\p=\p A_\p$, i.e.\ iff $f\notin\p$.

\blemm[title={The Qcqs lemma}, name={qcqslemm}]

    Suppose $X$ is a quasicompact quasiseparated scheme, $\F$ a quasicoherent sheaf on $X$, and $f\in X$.
    Then the restriction map
    $$ \res_{X_f\subseteq X} \colon \Gamma(X,\F) \to \Gamma(X_f,\F) $$
    is precisely the localization by $f$ map.

\elemm

\bproof

    Because $X$ is qcqs it is covered by finitely many affine subschemes, the pairwise intersections of which are covered by finitely many affine subschemes.
    So suppose $X=\bigcup_iU_i$ is a finite affine covering, and $U_i\cap U_j=\bigcup_kU_{ijk}$ is a finite affine covering for all $i,j$.

    The sheaf condition on $\F$ necessitates that the following sequence is exact (the arrows are the standard arrows):
    $$ 0 \to \Gamma(X,\F) \to \bigoplus_i\Gamma(U_i,\F) \to \bigoplus_{i,j,k}\Gamma(U_{ijk},\F) . $$
    This is because the direct sums are finite and thus are equivalently products.
    Localization by $f$ is exact and commutes with direct sums, so the following sequence is also exact:
    $$ 0 \to \Gamma(X,\F)_f \to \bigoplus_i\Gamma(U_i,\F)_f \to \bigoplus_{i,j,k}\Gamma(U_{ijk},\F)_f . $$

    Now for an affine $\spec A\subseteq X$, $\F|_{\spec A}\cong\tilde M$ for some $A$-module $M$.
    Then
    $$ \Gamma((\spec A)_f,\F) = \Gamma(\spec A_f,\F) = M_f . $$
    Thus we have an exact sequence
    $$ 0 \to \Gamma(X,\F)_f \to \bigoplus_i\Gamma((U_i)_f,\F) \to \bigoplus_{i,j,k}\Gamma((U_{ijk})_f,\F) $$
    and the last arrow is the usual one induced from restrictions.

    But the kernel of this map is $\Gamma(X_f,\F)$ as per the sheaf axiom.
    Thus we get the desired result.
    \qed

\eproof

Our goal now is to show that $\QCoh_X\subseteq\Mod_{\O_X}$ is an Abelian category.
In general if $\B\subseteq\A$ is a full subcategory of an Abelian category $\A$, then for $\B$ to be an Abelian category itself it is sufficient that
\benum
    \item $\B$ contain $\A$'s zero element,
    \item $\B$ be closed under finite sums,
    \item $\B$ be closed under kernels and cokernels.
\eenum
Indeed, if $\B$ is closed under colimits taken in $\A$, then those are $\B$'s colimits as well.
Thus if $f$ is monic in $\B$, then $\ker f=0$ as the kernel of a monic is zero, and thus $f=\ker\coker f$ in $\A$ and thus in $\B$.
Similar for epimorphisms.

Clearly the zero $\O_X$-module is quasicoherent.
And (2) follows from the fact that $\tilde M\oplus\tilde N\cong\tilde{M\oplus N}$, so the sum of quasicoherent sheaves is quasicoherent.
For (3) if $\alpha\colon\F\to\G$ is a morphism of quasicoherent sheaves, then let $U\subseteq X$ be affine, and denote by $\beta\colon M\to N$ the induced morphism of $A$-modules.
We then {\it define\/} $\ker\alpha(U)=\ker\beta$ and $\coker\alpha(U)=\coker\beta$.
Because localization is exact, it commutes with kernels and cokernels, we see that on $U$, $\ker\alpha\cong\tilde{\ker\beta}$ and $\coker\alpha\cong\tilde{\coker\beta}$.
This definition forms a sheaf on the distinguished affine base, so $\ker\alpha,\coker\alpha$ are quasicoherent sheaves.

Recall that exactness can be checked stalk-locally.
Thus it can be checked on an affine cover, which shows that
$$ 0 \to \ker\alpha \to \F \xtos\alpha \G \to \coker\alpha \to 0 $$
is exact, as it resorts to checking on affine subschemes, which just gives
$$ 0 \to \ker\beta \to M \xtos\beta N \to \coker\beta \to 0 . $$

So we have proven the following.

\bthrm

    $\QCoh_X$ is an Abelian subcategory of $\Mod_{\O_X}$.

\ethrm

For the last part of this section, we will show an alternative method of defining quasicoherent sheaves, such that the definition works for any ringed space.
Because manifolds are also examples of ringed spaces, this allows us to define quasicoherent sheaves on a manifold.

\bprop

    Let $A$ be a ring, then there is an adjunction
    $$ \Mod_A \adjarrow{\tilde\bul}{\Gamma} \Mod_{\O_{\spec A}} $$
    between $M\mapsto\tilde M$ and global sections $\F\mapsto\Gamma(\spec A,\F)$.

\eprop

\bproof

    This just amounts to showing that global sections
    $$ \hom_{\spec A}(\tilde M,\F) \xtos\Gamma \hom_A(M,\Gamma\F) $$
    is bijective.
    This is clear because if $\phi\colon M\to\Gamma\F$ is a module map then for any $f\in A$ by localization there is a unique $\phi_f$ making the following diagram commute

    \commsq{M&\Gamma(\spec A,\F)\cr M_f&\Gamma(\spec A_f,\F)}
        {\phi}{\phi_f}{}{}

    It is easy to see that the $\phi_f$ assemble into a $\O_{\spec A}$-module morphism.
    Existence and uniqueness shows that $\Gamma$ is a bijection.
    \qed

\eproof

In particular $M\mapsto\tilde M$ commutes with colimits.

\bprop[name={qcoherentgeneral}]

    Let $X$ be a scheme.
    An $\O_X$-module is quasicoherent iff there exists an open cover $X=\bigcup_iU_i$ such that for all $i$, $\F|_{U_i}$ fits into an exact sequence
    $$ \O_{U_i}^{\oplus I} \to \O_{U_i}^{\oplus J} \to \F|_{U_i} \to 0 . $$

\eprop

\bproof

    If $\F$ is a quasicoherent sheaf take $U_i$ to be an affine open cover.
    For an affine $\spec A\subseteq X$ we have that
    $$ \O_{\spec A}^{\oplus I} \cong (\tilde A)^{\oplus I} \cong \tilde{A^{\oplus I}} . $$
    Now if $\F|_{\spec A}\cong\tilde M$ then $M$ fits into an exact sequence
    $$ A^{\oplus I} \to A^{\oplus J} \to M \to 0 . $$
    Because $\tilde\bul$ is a left-adjoint and thus right-exact, we have that the following sequence
    $$ \matrix{
        \tilde{A^{\oplus I}} &\to& \tilde{A^{\oplus J}} &\to& \tilde M &\to& 0\cr
        \cong && \cong && \cong\cr
        \O_{\spec A}^{\oplus I} &\to& \O_{\spec A}^{\oplus J} &\to& \F|_{\spec A} &\to& 0
    } $$
    is exact, as desired.

    Conversely if such an open cover exists, then we can refine it to be an affine cover.
    Because restricting $\O_X\mapsto\O_U$ is exact, we can just assume the cover to be affine.
    Thus we have for every $\spec A\subseteq X$ in the cover, an exact sequence
    $$ \tilde{A^{\oplus I}} \to \tilde{A^{\oplus J}} \to \F|_{\spec A} \to 0 . $$
    Let $M=\coker(A^{\oplus I}\to A^{\oplus J})$, so we have an exact sequence
    $$ A^{\oplus I} \to A^{\oplus J} \to M \to 0 . $$
    Applying $\tilde\bul$ then gives us the exact sequence
    $$ \tilde{A^{\oplus I}} \to \tilde{A^{\oplus J}} \to \tilde M \to 0 , $$
    and the first arrow is the same as the previous one because $\tilde\bul$ and global sections are inverses from $A$-modules.

    Thus we must have that $\F|_{\spec A}\cong\tilde M$, meaning $\F$ is quasicoherent as desired.
    \qed

\eproof

Thus for a general ringed space $(X,\O_X)$ we can take the condition in the above proposition as the definition of quasicoherence.

In fact we can do a bit better.
Let $(X,\O_X)$ be a ringed space with a ring of global sections $A=\O_X(X)$.
Then for a module $M\in\Mod_A$ we can define its {\emphcolor associated presheaf} to be $\tilde M_\pre\in\Mod^\pre_{\O_X}$ by
$$ \tilde M_\pre(U) = \O_X(U)\otimes_{\O_X(X)} M ,\qquad U\subseteq X\hbox{ open} . $$
Its {\emphcolor associated sheaf} is then the sheafification $\tilde M=\tilde M_\pre^\sh$.
These constructions are clearly functorial.

A first remark is that when $X=\spec A$ then the associated presheaf of $M$ is the associated sheaf because
$$ \tilde M(\dof f) = M_f = A_f\otimes M = \O_{\spec A}(\dof f)\otimes_AM . $$
And in general the associated presheaf, and thus sheaf, of $A=\O_X(X)$ is $X$:
$$ \tilde A(U) = \O_X(U)\otimes_AA = \O_X(U) . $$

Now an open subsheaf of an associated sheaf is itself an associated sheaf.
More precisely if $\tilde M$ is an associated sheaf of $\O_X$, then for $U\subseteq X$ open $\tilde M|_U=\varwidetilde{\O_X(U)\otimes_{\O_X(X)}M}$.
This is clearly true for the associated presheaf.
Because restriction is left adjoint to $\inc_*$ for inclusion $U\inj X$, both for presheaves and sheaves, we see that sheafification commutes with restriction.
Indeed, sheafification is left adjoint to inclusion $\Sh(X)\inj\Psh(X)$, and this commutes with $\inc_*$, so sheafification and restriction does as well.
Thus
$$ \varwidetilde{\O_X(U)\otimes_{\O_X(X)}M} = \varwidetilde{\O_X(U)\otimes M}_\pre^\sh = \tilde M_\pre|_U^\sh = \tilde M_\pre^\sh|_U = \tilde M|_U . $$

\bprop

    Let $(X,\O_X)$ be a ringed space and $A=\O_X(X)$.
    Then there is an adjunction
    $$ \Mod_A \adjarrow{\tilde\bul}{\Gamma} \Mod_{\O_X} . $$

\eprop

\bproof

    First we show this for presheaves: there is an adjunction
    $$ \Mod_A \adjarrow{\tilde\bul^\pre}{\Gamma} \Mod^\pre_{\O_X} . $$
    In this case for an $A$-module $M$ and an $\O_X$-module $\F$, global sections forms a bijection:
    $$ \hom_{\O_X}(\tilde M,\F) \xtos\Gamma \hom_A(M,\Gamma(X,\F)) . $$
    Indeed recall that for an $A$-module $B$, $B\otimes_A\bul$ is left-adjoint to the forgetful functor $\Mod_B\to\Mod_A$.
    Thus for any open $U\subseteq X$, there is a unique morphism $\tilde M(U)\to\F(U)$ making the following diagram commute:

    \diagram{
        M&\Gamma(X,\F)\cr
        \O_X(U)\otimes M&\Gamma(U,\F)
    }{
        \diagarrow{from={1,1}, to={1,2}}
        \diagarrow{from={1,1}, to={2,1}}
        \diagarrow{from={1,2}, to={2,2}}
        \diagarrow{from={2,1}, to={2,2}, text={\exists!}, y distance=.25cm}
    }

    This demonstrates both uniqueness and existence (verifying this for $U\subseteq V$ instead of just $V=X$).

    So we have a chain of adjunctions
    $$ \Mod_A \adjarrow{\tilde\bul^\pre}{\Gamma} \Mod^\pre_{\O_X} \adjarrow{\sh}{\inc} \Mod_{\O_X} , $$
    so that $\sh\circ\tilde\bul^\pre=\tilde\bul$ is left adjoint to $\Gamma\circ\inc=\Gamma$ as desired.
    \qed

\eproof

\blemm

    An $\O_X$-module $\F$ is associated iff there is an exact sequence
    $$ \O_X^{\oplus I} \to \O_X^{\oplus J} \to \F \to 0 . $$

\elemm

\bproof

    If $\F=\tilde M$ is associated, then there are $I,J$ making the following sequence exact:
    $$ A^{\oplus I} \to A^{\oplus J} \to M \to 0 ,\qquad A=\O_X(X) . $$
    Because $\tilde\bul$ is a left adjoint, it preserves direct sums and is right-exact.
    Furthermore because $\tilde A=\O_X$, applying $\tilde\bul$ gives an exact sequence
    $$ \O_X^{\oplus I} \to \O_X^{\oplus J} \to \tilde M \to 0 . $$

    Conversely if there is an exact sequence
    $$ \O_X^{\oplus I} \to \O_X^{\oplus J} \to \F \to 0 , $$
    then let $M$ fit into the exact sequence
    $$ A^{\oplus I} \to A^{\oplus J} \to M \to 0 . $$
    As before applying $\tilde\bul$ gives the exact sequence
    $$ \O_X^{\oplus I} \to \O_X^{\oplus J} \to \tilde M \to 0 , $$
    and thus $\tilde F\cong\tilde M$.
    \qed

\eproof

Say that an $\O_X$-module is {\emphcolor locally associated} if for every $p\in X$ there is a neighborhood $p\in U$ such that $\F|_U$ is an associated $\O_U$-module.
The previous lemma then gives the following corollary immediately.

\bcoro

    An $\O_X$-module is quasicoherent iff it is locally associated.

\ecoro

Because open subsheaves of an associated sheaf are associated, if $X$ is a scheme we see that it is locally associated iff every point lies in an {\it affine\/} neighborhood
in which it is associated.
Thus this corollary shows that quasicoherence, as defined in general, corresponds to quasicoherence defined over schemes.
The proof of this is essentially the same as the one given \refmath[proposition]{qcoherentgeneral}.

\subsubsection{Finiteness of quasicoherent sheaves}

For an $A$-module $M$, there are three finiteness conditions we care about:
\benum
    \item $M$ is {\emphcolor finitely generated}: it has a finite number of generators.
    Equivalently there is a surjection $A^{\oplus n}\to M$ for a finite $n$.
    \item $M$ is {\emphcolor finitely presented}: it has a finite number of generators and a finite number of relations.
    Equivalently there is a {\emphcolor finite presentation}: an exact sequence
    $$ A^{\oplus m} \to A^{\oplus n} \to M \to 0 . $$
    \item $M$ is {\emphcolor coherent}: it is finitely generated, and for any (not necessarily surjective) map $A^{\oplus n}\to M$, its kernel is finitely generated.
\eenum

Note that being finitely presented is equivalent to there being a surjection $A^{\oplus n}\to M$ whose kernel is finitely generated.
Indeed if $A^{\oplus m}\to A^{\oplus n}\to M\to0$ is exact, then the kernel of $A^{\oplus n}\to M$ is the image of a map from $A^{\oplus m}$, which is finitely generated.
Conversely if $A^{\oplus n}\to M$ has finitely generated kernel $K$, take a surjection $A^{\oplus m}\to K$; the composition $A^{\oplus m}\to A^{\oplus n}\to M\to0$ is exact.

Thus coherence implies finitely presented.
Clearly finitely presented implies finitely generated.
We will show that if $A$ is Noetherian, finitely generated implies coherence.

\bprop

    If $A$ is Noetherian, all three finiteness conditions above are equivalent.

\eprop

\bproof

    Suppose $M$ is a finitely generated $A$-module, and take a map $\alpha\colon A^{\oplus m}\to M$.
    Then $\ker\alpha$ is a submodule of $A^{\oplus m}$, which is Noetherian as the finite sum of Noetherian modules, and thus $\ker\alpha$ is Noetherian.
    In particular $\ker\alpha$ is finitely generated.
    \qed

\eproof

If $A$ is Noetherian, then the category of finitely generated $A$-modules is an Abelian subcategory of $\Mod_A$.
Indeed, the zero module is finitely generated, and the sum of two finitely generated $A$-modules is finitely generated.
We just need to show that the kernel and cokernel of a map between finitely generated $A$-modules is finitely generated.
The cokernel is a quotient of its codomain and is thus finitely generated.
The kernel is a submodule of the domain; since the domain is finitely generated, it is Noetherian so its submodules are finitely generated.

In fact even when $A$ is not Noetherian, the category of coherent $A$-modules is an Abelian subcategory of $\Mod_A$.
We ignore the proof.

\bprop

    The category of coherent $A$-modules is a full Abelian subcategory of $\Mod_A$.

\eprop

Note that the localization of finitely generated modules are finitely generated: if $M$ is a finitely generated $A$-module, then $S^{-1}M$ is a finitely generated $S^{-1}A$-module.
Conversely if $A=(f_1,\dots,f_n)$ and $M_{f_i}$ is a finitely generated $A_{f_i}$-module, then $M$ is a finitely generated $A$-module.
Suppose $m_{ij}\in M$ generate $M_{f_i}$, then all the $m_{ij}$ generate $M$.
Indeed, for $m\in M$ there are $a_{ij}\in A$ and $k_i\geq0$ such that for all $i$:
$$ m = \frac{\sum_j a_{ij}m_{ij}}{f_i^{k_i}} \iff f_i^{N_i}\parens{f_i^{k_i}m - \sum_j a_{ij}m_{ij}} $$
for some $N_i\geq0$.
We can assume that all the $N_i$ and $k_i$ are equal, and by updating $a_{ij}$ to be $f_i^{N_i}a_{ij}$ we get that
$$ f_i^Nm = \sum_ja_{ij}m_{ij} . $$
Because $(f_i)_i$ is the unit ideal, so too is $(f_i^N)_i$ (because its radical is $(f_i)_i$ and $\sqrt I=(1)$ iff $I=(1)$).
Thus there are $c_i\in A$ such that $\sum_ic_if_i^N=1$ and thus
$$ m = \sum_ic_if_i^Nm = \sum_{i,j}c_ia_{ij}m_{ij} $$
as desired.

We summarize this as follows.

\bprop

    Let $M$ be an $A$-module.
    \benum
        \item If $M$ is a finitely generated $A$-module, then $S^{-1}M$ is a finitely-generated $S^{-1}A$-module.
        \item If $A=(f_1,\dots,f_n)$ and $M_{f_i}$ is a finitely-generated $A_{f_i}$-module for all $i$, then $M$ is a finitely generated $A$-module.
    \eenum

\eprop

\blemm

    Suppose $M$ is a finitely presented $A$-module.
    Then for any surjection $\phi\colon A^{\oplus p}\to M$, its kernel is finitely generated.

\elemm

\bproof

    Choose a finite presentation of $M$:

    \diagram{
        &&A^{\oplus p}\cr
        A^{\oplus m}&A^{\oplus n}&M&0\cr
        &&0
    }{
        \diagarrow{from={2,1}, to={2,2}, text=\beta, y distance=.25cm}
        \diagarrow{from={2,2}, to={2,3}, text=\alpha, y distance=.25cm}
        \diagarrow{from={1,3}, to={2,3}, text=\phi, x distance=.25cm}
        \diagarrow{from={2,3}, to={2,4}}
        \diagarrow{from={2,3}, to={3,3}}
    }

    Because the rings are free, we can find lifts $g,h$ making the following diagram commute

    \diagram{
        &&A^{\oplus p}\cr
        A^{\oplus m}&A^{\oplus n}&M&0\cr
        &&0
    }{
        \diagarrow{from={2,1}, to={2,2}, text=\beta, y distance=.25cm}
        \diagarrow{from={2,2}, to={2,3}, text=\alpha, y distance=.25cm}
        \diagarrow{from={1,3}, to={2,3}, text=\phi, x distance=.25cm}
        \diagarrow{from={2,3}, to={2,4}}
        \diagarrow{from={2,3}, to={3,3}}
        \diagarrow{from={1,3}, to={2,2}, text=g, x distance=-.25cm, x off=-.1cm}
        \diagarrow{from={2,2}, to={1,3}, text=h, x distance=.25cm, x off=.1cm}
    }

    Explicitly, if $x_1,\dots,x_p$ generate $A^{\oplus p}$ then by surjectivity there are $y_i\in A^{\oplus n}$ such that $\alpha(y_i)=\phi(x_i)$.
    So define $g(x_i)=y_i$.

    Now consider the following sequence
    $$ A^{\oplus m}\oplus A^{\oplus k} \xtos\psi A^{\oplus k} \xtos\phi M \to 0,\qquad \psi = (h\circ\beta)\oplus(\id-h\circ g) . $$
    We claim that this sequence is exact, and then we are finished.
    Firsly,
    $$ \phi\circ h\circ\beta = \alpha\circ\beta = 0,\qquad \phi - \phi\circ h\circ g = \phi - \alpha\circ g = \phi - \phi = 0 $$
    so that $\phi\circ\psi=0$.
    Now if $x\in\ker\phi$ we want to find a $y\in A^{\oplus m}$ such that
    $$ x = \psi(y+x) = h(\beta(y)) + x - h(g(x)) \iff h(\beta(y)) = h(g(x)) . $$
    Now if $\phi x=0$ then $\alpha gx=0$ so $gx\in\ker\alpha=\im\beta$, so there is a $y\in A^{\oplus m}$ such that $\beta y=gx$.
    Thus $h\beta y=hgx$ as desired.
    \qed

\eproof

We already showed that finitely generated modules satisfy the hypothesis of the affine communication lemma.
We now show this for finite presentations and coherence.

\blemm

    Let $M$ be an $A$-module.
    \benum
        \item If $M$ is finitely presented, then $S^{-1}M$ is finitely presented as an $S^{-1}A$-module.
        \item If $(f_1,\dots,f_n)=A$ and $M_{f_i}$ is a finitely presented $A_{f_i}$-module for all $i$, then $M$ is a finitely presented $A$-module.
    \eenum

\elemm

\bproof

    (1) is clear because localization is exact.
    For (2) we know then that $M$ is finitely generated.
    Thus there is a surjection $\phi\colon A^{\oplus n}\to M$, and its localizations $\phi_{f_i}\colon A_{f_i}^{\oplus n}\to M_{f_i}$ are all surjective as well (as localization is exact).
    By the above lemma, this means that $\ker(\phi_{f_i})$ is finitely generated.
    Because $\ker(\phi_{f_i})\cong(\ker\phi)_{f_i}$, this means that $(\ker\phi)_{f_i}$ is finitely generated for all $i$, and thus $\ker\phi$ is.
    \qed

\eproof

For coherence we note that $M$ is coherent iff it is finitely generated and all of its finitely generated submodules are finitely presented.
Indeed if $M$ is coherent and $N\subseteq M$ is a finitely generated submodule, let $A^{\oplus n}\to N$ be a surjection.
Then the composition $A^{\oplus n}\to N\inj M$ has a finitely generated kernel, so $N$ is finitely presented.
Conversely suppose all of $M$'s finitely generated submodules are finitely presented.
Let $\phi\colon A^{\oplus n}\to M$ be any map, then consider its kernel $K$.
Then $A^{\oplus n}/K$ is a submodule of $M$, thus finitely presented, and so by the above lemma the kernel of $A^{\oplus n}\to A^{\oplus n}/K$, which is $K$, is finitely generated.

In particular a finitely generated submodule of a coherent module is coherent.

\blemm

    Let $M$ be an $A$-module.
    \benum
        \item If $M$ is coherent, then $S^{-1}M$ is coherent as an $S^{-1}A$-module.
        \item If $(f_1,\dots,f_n)=A$ and $M_{f_i}$ is a coherent $A_{f_i}$-module for all $i$, then $M$ is a coherent $A$-module.
    \eenum

\elemm

\bproof

    For (1) if $N'\subseteq S^{-1}M$ is a finitely generated submodule, then $N'=S^{-1}N$ for a finitely generated submodule $N\subseteq M$ (if $x_i/s_i$ generate $N'$
    then take $N$ generated by $x_i$).
    Then since $M$ is coherent, $N$ is finitely presented, and so by the previous lemma $N'=S^{-1}N$ is finitely presented as well.
    Thus $S^{-1}M$ is coherent.

    For (2) let $N\subseteq M$ be finitely generated.
    Then $N_{f_i}\subseteq M_{f_i}$ is finitely generated, thus finitely presented.
    This is true for all $i$ so by the previous lemma, $N$ is finitely generated.
    Thus $M$ is coherent.
    \qed

\eproof

\bdefn

    A quasicoherent sheaf $\F$ is {\emphcolor finite type} (resp.\ {\emphcolor finitely presented}, {\emphcolor coherent}) if for every affine open $\spec A\subseteq X$,
    $\Gamma(\spec A,\F)$ is a finitely generated (resp.\ finitely presented, coherent) $A$-module.

\edefn

Note that coherent quasicoherent sheaves are finitely presented, which in turn are finitely generated.
Because these three notions are equivalent over a Noetherian ring, these three notions are equivalent over a locally Noetherian scheme.

Because coherent modules are an Abelian subcategory of $A$-modules, coherent quasicoherent sheaves form an Abelian subcategory of $\QCoh_X$.
This can be seen because our construction of the kernel and cokernel of $\alpha\colon\F\to\G$ is the (co)kernel of $\beta\colon M\to N$, and $M,N$ are coherent so the (co)kernel
of $\beta$ is as well.

Just like how quasicoherence can be generalized to arbitrary ringed spaces, so too can finite type, finitely presented, and coherence.

\bdefn

    Let $(X,\O_X)$ be a ringed space and $\F$ an $\O_X$-module.
    \benum
        \item $\F$ is {\emphcolor finite type} if for every $x\in X$ there is an open $x\in U\subseteq X$ and a surjection
        $$ \O_U^{\oplus n} \to \F|_U \to 0 $$
        for some $n\geq0$.
        \item $\F$ is {\emphcolor finitely presentable} if for every $x\in X$ there is an open $x\in U\subseteq X$ and $n,m\geq0$ and an exact sequence
        $$ \O_U^{\oplus m} \to \O_U^{\oplus n} \to \F|_U . $$
        \item $\F$ is {\emphcolor coherent} if $\F$ is finite type and for all open $U\subseteq X$, the kernel of any map
        $$ \O_U^{\oplus n} \to \F|_U $$
        is of finite type.
    \eenum

\edefn

If $\F$ is quasicoherent these definitions agree with our previous definitions.
Indeed the neighborhoods in (1) and (2) may be assumed to be affine, and because global sections and $\tilde\bul$ form an equivalence on $\Mod_A$ we get the desired result.
And by taking $U$ to be affine, we see that (3) implies that $\F$ is coherent (as in the previous definition).
And because finite type can be taken locally, in (3) it is sufficient to consider only any open cover, so coherence implies (3).

\subsubsection{Simple objects and length}

For the remainder of this section $\C$ is an Abelian category.

\bdefn

    An object $M\in\C$ is {\emphcolor simple} if its only subobjects are $0$ and $M$ itself.
    A {\emphcolor composition series} for an arbitrary object $M\in\C$ is a finite filtration
    $$ 0 = X_0 \subsetneq X_1 \subsetneq \cdots \subsetneq X_{n-1} \subsetneq X_n = M $$
    such that the quotients $X_{i+1}/X_i$ are all simple.
    The {\emphcolor length} of this composition series is $n$.
    An object with a composition series is said to have {\emphcolor finite length}.

\edefn

\bthrm[title={Jordan-H\"older}, name={jordhold}]

    If $M$ is of finite length, then all of its composition series have the same length.
    Furthermore, up to permutation, the quotients of any composition series of $M$ are the same.

\ethrm

\bproof

    Suppose $0=X_0\subsetneq X_1\subsetneq\cdots\subsetneq X_n=M$ and $0=Y_0\subsetneq Y_1\subsetneq\cdots\subsetneq Y_p=M$ are two composition series.
    Define $Z_{ij}=X_i\cap Y_j\subseteq M$ (this is the pullback of $X_i\to M\ot Y_j$).
    For reasons of abstract nonsense, the following are true:
    \benum
        \item if $i\leq i'$ and $j\leq j'$, $Z_{i,j}\subseteq Z_{i',j'}$;
        \item $Z_{n,j}=Y_j$ and $Z_{i,p}=X_i$;
        \item $Z_{0,j}=Z_{i,0}=0$;
        \item $Z_{i,j}\cap Z_{i',j'}=Z_{\min(i,i'),\min(j,j')}$.
    \eenum
    The core of (1) and (4) is that $A\to X\times_MY$ is monic if the composition $A\to X\times_MY\to X$ is.

    Now notice that the kernel of $Z_{ij}\to Z_{i+1,j}/Z_{i+1,j-1}$ is $Z_{ij}\cap Z_{i+1,j-1}=Z_{i,j-1}$.
    Thus we have that $Z_{ij}/Z_{i,j-1}\subseteq Z_{i+1,j}/Z_{i+1,j-1}$.
    Inductively then we have that $Z_{ij}/Z_{i,j-1}$ is either $0$ or $Y_j/Y_{j-1}$.
    For $i=n$ this is clear as $Z_{nj}=Y_j$, and then inductively we have that $Z_{ij}/Z_{i,j-1}\subseteq Z_{i+1,j}/Z_{i+1,j-1}=Y_j/Y_{j-1}$.
    This is simple, so we have the desired result.
    Similarly $Z_{ij}/Z_{i-1,j}$ is either $0$ or $X_i/X_{i-1}$.

    Now define a matrix whose entries are $Z_{ij}$.
    Then between adjacent cells, draw a line if the quotient is nonzero.
    So for example if $Z_{ij}/Z_{i-1,j}$ is nonzero then draw a line between the $(i-1,j)$th and $(i,j)$th cell.

    Take any $2\times2$ submatrix
    $$ \matrix{Z_{ij}&Z_{i,j+1}\cr Z_{i+1,j}&Z_{i+1,j+1}} = \matrix{A&B\cr C&D} . $$
    We claim that the drawn lines are of one of the following five forms:
    $$ \drawcross xx..\qquad \drawcross ..xx\qquad \drawcross ....\qquad \drawcross .x.x\qquad \drawcross xxxx $$
    We know that $A=B\cap C$, so if $B=D$ then $A=C$.
    And if $C=D$ then $A=B$; this takes care of the first three cases.
    Otherwise suppose $D/B$ and $D/C$ are both nonzero.
    If $B=C$ then $A=B=C$ so that we are in the fourth case.

    Otherwise we will see that $D/B\cong C/A$ and similarly $D/C\cong B/A$ so that we are in the last case.
    Indeed consider the map $C\to D/B$ which has kernel $C\cap B=A$, so we have an injection $C/A\inj D/B$.
    Because $D/B$ is simple, either $C/A$ is zero or this is an isomorphism; but if $A=C$ then $C\subseteq B$ so we have a map $D/C\to D/B$.
    Because $D/C$ is simple, this map is either the zero map or an injection (considering the kernel).
    If if it is an injection it is an isomorphism and thus $B=C$, a contradiction.
    But if it is the zero map this means that one of $D/C$ or $D/B$ is zero, contradicting that they are nonzero.
    Thus $C/A\cong D/B$ and similarly $B/A\cong D/C$, so we are in the fifth case.

    Furthermore note that in all of the cases except the last, the bold lines are all isomorphic.
    In the the first case we have $D=B$ and $C=A$ so $B/A=D/C$.
    Similarly for the second.
    In the fourth case, $B=C=A$ so $D/B=D/C$.
    In the fifth case we saw that $D/B=C/A$ and $D/C=B/A$, so the straight lines are isomorphic (i.e.\ the two horizontal lines are isomorphic to one another, similar for vertical).

    Note that on the rightmost and bottomost edge of the matrix, all of the horizontal lines are colored: $Z_{i,p}/Z_{i-1,p}$ and $Z_{n,j}/Z_{n,j-1}$
    are isomorphic to the nonzero $X_i/X_{i-1}$ and $Y_j/Y_{j-1}$ respectively.
    Thus for any $Y_j/Y_{j-1}$ we can follow the bold line all the way to the left and then make one turn downwards.
    This brings us to a $X_i/X_{i-1}$, and because the bold lines are isomorphic, we have that $Y_j/Y_{j-1}\cong X_i/X_{i-1}$.
    We can do this for $X_i/X_{i-1}$ as well, and these processes are inverses.
    \qed

\eproof

\bdefn

    Let $M\in\C$ be of finite length.
    Its {\emphcolor length} is the length of any of its composition series, and is denoted by $\ell(M)$.
    If $M$ is not of finite length then define $\ell(M)=\infty$.

    This is well-defined in lieu of Jordan-H\"older.

\edefn


Note that subobjects of $A/B$ are in correspondence with subobjects of $A$ containing $B$.
Indeed if $B\subseteq M\subseteq A$ then the kernel of $M\to A/B$ is $M\cap B=B$ so this gives an injection $M/B\inj A/B$.
Conversely if $N\subseteq A/B$ is a subobject, consider the pullback $M=N\times_{A/B}A$.
Because $B\inj A$, we have that $B\inj M$ ($B\inj A$ commutes with the zero map $B\to N$).
These are mutual inverses.

Now if $M$ has finite length, then so too do all of its subquotients.
That is if we have a filtration $0\subseteq M'\subseteq M''\subseteq M$, then $M''/M'$ has finite length.
Let $M_\bul$ be a composition series for $M$, then create a matrix as in the Jordan-H\"older theorem proof, whose cells are the intersections of $M_\bul$ with $0\subseteq M'\subseteq M''\subseteq M$.

The horizontal lines in the matrix are all either zero or simple.
This is because the kernel of $M_{i+1}\cap M'\inj M_{i+1}/M_i$ is $M_i\cap M'$ so $(M_{i+1}\cap M')/(M_i\cap M')$ is a subobject of $M_{i+1}/M_i$.
Meanwhile the vertical lines are subobjects of $M''/M'$ (or $M/M''$, $M'$): the kernel of $M_i\cap M''\to M''/M'$ is $M_i\cap M'$ so $(M_i\cap M'')/(M_i\cap M')$ is a subobject of $M''/M'$.

The possible submatrices here are the same as in the proof above, except we have one additional option:
$$ \drawcross xx.x . $$
This is because if $D/B,D/C$ are nonzero and $B\neq C$, then we have an injection $C\to D/B$.
As before this has kernel $A$ so $C/A\subseteq D/B$.
Here it may be that $A=C$ so $C\subseteq B$.

If we take a horizontal line $M_i/M_{i-1}$ and follow the path which goes as left as possible and then down, we will either land on the line $M''/M'$ or not.
If it does land on $M''/M'$ then keep track of the first vertical line in the path.
This is a subobject of $M''/M'$, and we claim that these form a composition series of $M''/M'$.

We show two things:
\benum
    \item $B/A$ is a subobject of $D/C$,
    \item $\frac{D/C}{B/A}$ is either zero or simple.
\eenum
For (1), the kernel of $B\to D/C$ is $A$ so this is immediate.
For (2), we split into non-trivial cases: in
$$ \drawcross xx.. $$
we have $D=B$ and $C=A$ so
$$ \frac{D/C}{B/A} = \frac{B/C}{B/C} = 0 . $$
And in
$$ \drawcross .x.x $$
we have $A=B=C$ so
$$ \frac{D/C}{B/A} = \frac{D/B}{A/A} = D/B $$
which is simple as the horizontal lines are simple.
And in
$$ \drawcross xx.x $$
we have $A=C$ so
$$ \frac{D/C}{B/A} = \frac{D/A}{B/A} = D/B $$
is simple.
FInally in
$$ \drawcross xxxx $$
we have $D/B\cong C/A$.
Consider then the map $D\to(D/C)/(B/A)$ which is a surjection and $B$ is a subobject of the kernel.
So this quotients to a surjection $D/B\to(D/C)/(B/A)$, which is either an isomorphism or $(D/C)/(B/A)=0$.
This is because a simple object has no nontrivial quotients.

This means that by following these paths (left then down), the first vertical lines form a composition series of $M''/M'$.

Thus any filtration of a finite-length object $M$ can be refined into a composition series.
Indeed suppose $M'\subseteq M$, then we can find a composition series of $M/M'$.
Because modules of $M/M'$ correspond to modules $M'\subseteq M''\subseteq M$, this forms a series $M'=M_0\subsetneq M_1\subsetneq\cdots\subsetneq M_n=M$
whose quotients are simple.
So if we have a filtration $0=M_0\subsetneq\cdots\subsetneq M_n=M$, doing this for every $M_i\subsetneq M_{i+1}$ gives the desired composition series.

In this same way we see that if $M'\subseteq M$ is a subobject then
$$ \ell(M) = \ell(M') + \ell(M/M') . $$
This is because a composition series of $M/M'$ corresponds to a filtration of $M'\subseteq M$ whose quotients are simple.
Appending this to a composition series of $M'$ gives a composition series of $M$.
Note that this works without any assumptions on the objects: even if $M$ is not of finite length, this identity holds.

Another way of writing this is that length is additive:
$$ 0 \to M' \to M \to M'' \to 0 \quad\implies\quad \ell(M) = \ell(M') + \ell(M'') . $$

Thus the sum of two finite length objects is finite length, due to the exact sequence $0\to M\to M\oplus N\to N\to0$.
And subobjects and quotients of finite length objects are also of finite length, in particular kernels and cokernels are.
Thus the full subcategory of $\C$ consisting of objects of finite length is Abelian.

Now we focus on the case $\C=\Mod_A$ where $A$ is a ring.
Let us assume that $A$ is not necessarily commutative, then simple modules are those which are isomorphic to $A/\m$ for a maximal right ideal $\m\leq A$.
All such modules are simple, because there are no right ideals between $\m$ and $A$.
Note that $A/I$ is simple iff $I$ is a maximal right ideal, otherwise there is a $I\subsetneq J\subsetneq A$ and then $J/I\leq A/I$ is a non-trivial submodule.

And if $M$ is a simple module, let $m\in M$ be nonzero.
Now consider $f\colon A\to M$ given by $f(a)=am$.
Then $\im f$ is a nonzero submodule of $M$, so it must be all of $M$.
Thus $A/\ker f\cong M$ is simple, and thus $\ker f$ must be maximal as per the previous paragraph.

So in the case that $A$ is commutative, the simple modules in $\Mod_A$ are fields which are surjected onto by $A$.

\blemm

    Suppose $M$ is a finite-length module, and $M_\bul$ is a composition series for $M$.
    Now suppose that $M_i/M_{i-1}\cong A/\m_i$ where $\m_i\leq A$ are maximal ideals.
    Then $M$ is annihlated by $\m_1\cdots\m_n$, so it can be viewed as an $A/\m_1\cdots\m_n$-module.

\elemm

\bproof

    For each $i$ define $b_i=a_0\cdots a_i$.
    Then inductively we show that $b_i$ annihlates $M_i$.
    For $M_0=0$ this is clear.
    Now we know that for $m\in M_i$, $a_im\in M_i/M_{i-1}$ is zero, so $a_im\in M_{i-1}$.
    Thus by induction $b_im=b_{i-1}a_im=0$ as desired.
    \qed

\eproof

Now suppose that in the context of the above lemma, the maximal ideals are $(\m_1,\dots,\m_n)$.
Removing repeated maximal ideals suppose we have $\n_1,\dots,\n_s$ with multiplicities $\ell_1,\dots,\ell_s$.
Then by the chinese remainder theorem
$$ A/\m_1\cdots\m_n = \A/\n_1^{\ell_1}\cdots\n_s^{\ell_s} \cong A/\n_1^{\ell_1}\times\cdots\times A/\n_s^{\ell_s} . $$
For $1\leq i\leq s$ let $e_i\in A$ be the image of $(0,\dots,1,\dots,0)$, i.e.\ the unique element where $e_i\equiv1\pmod{\n_i^{\ell_i}}$ and $e_i\equiv0\pmod{\n_j^{\ell_j}}$ for $j\neq i$.

\blemm

    We have $M\cong e_1M\times\cdots\times e_sM$, and $e_iM$ is a finite-length module whose simple quotients are $A/\n_i$.

\elemm

\bproof

    The obvious map $M\to e_1M\times\cdots\times e_sM$, $m\mapsto(e_1m,\dots,e_sm)$, is injective.
    Indeed if $e_im=0$ for all $i$ then $(e_1+\cdots+e_n)m=0$, and $e_1+\cdots+e_n=1$ in $A/\m_1\cdots\m_n$.
    Since $M$ is an $A/\m_1\cdots\m_n$-module, this means $m=0$.

    This also shows that it is surjective: for $(e_1m_1,\dots,e_nm_n)\in e_1M\times\cdots\times e_sM$, let $m=e_1m_1+\cdots+e_nm_n$.
    Because $e_i^2=e_i$ and $e_ie_j=0$ for $i\neq j$ in $A/\m_1\cdots\m_n$, then we have $e_im=e_im_i$ as desired.

    Because $M$ is finite-length, so too are the $e_iM$ as submodules.
    Now consider $e_iM_j$, where $M_\bul$ is the composition series of $M$.
    Then $e_iM_j$ forms a filtration of $e_iM$, though some components may be equal.
    Consider the map $e_iM_j\to M_j/M_{j-1}$ which has kernel $e_iM_j\cap M_{j-1}\supseteq e_iM_{j-1}$.
    Now suppose $M_j/M_{j-1}\cong A/\n_k$.

    If $i=k$ then $e_i-1\in\n_k$ so that for all $m\in M_j$, $e_im-m\in M_{j-1}$.
    So if $e_im\in M_{j-1}$ then $m\in M_{j-1}$ and thus $e_im\in e_iM_{j-1}$; so $e_iM_j\cap M_{j-1}=e_iM_{j-1}$.
    Thus $e_iM_j/e_iM_{j-1}$ is a subobject of $M_j/M_{j-1}$, and so is either equal to zero or $A/\n_i$.

    Otherwise $e_i\in\n_k$ so that $e_im\in M_{j-1}$ for all $m\in M_j$, meaning $e_iM_j\subseteq M_{j-1}$.
    Thus $e_iM_j\cap M_{j-1}=e_iM_j$.
    And so the quotient is $e_iM_j/e_iM_{j-1}=0$.

    Thus the simple quotients of $e_iM$ are just $A/\n_i$ (as the other quotients are zero).
    \qed

\eproof

Note that if $M$ is a module with a composition series $M_i$ whose quotients are all isomorphic to $A/\m$, then $M_\p\neq0$ iff $\p=\m$.
Indeed the composition series gives us a filtration
$$ 0 = (M_0)_\p \subseteq \cdots \subseteq (M_n)_\p = M_\p . $$
Localization commutes with quotients, so the quotients here are
$$ \frac{(M_i)_\p}{(M_{i-1})_\p} = \parens{\frac{M_i}{M_{i-1}}}_\p = (A/\m)_\p = A_\p/\m A_\p . $$
Now $\m A_\p\neq A_\p$ iff $\m\subseteq\p$ iff $\p=\m$.
Thus if $\p\neq\m$ then the quotients are zero, meaning $M_\p=0$.
Thus
$$ \supp M = \set{\p\in\spec A}[M_\p\neq0] = \set\m . $$

Now if $M=M_1\times\cdots\times M_n$ where each $M_i$ has simple quotients all of the form $A/\m_i$, then
$$ \supp M = \bigcup_i\supp M_i = \set{\m_1,\dots,\m_n} . $$
The reason for the first equality is because localization commutes with finite products.

So by the previous lemma if $M$ has finite length, then $\supp M$ consists only of finitely many maximal ideals.
In other words, $\supp M$ is a finite subset of closed points of $\spec A$.

Because $\QCoh_X$ is Abelian, there is a notion of simple objects and length.
Our goal is to try and understand these objects.

\subsubsection{Associated points}

Recall that for an $A$-module $M$ and $m\in M$,
$$ \supp m = \set{\p\in\spec A}[m_\p\neq0] . $$
Define the annihilator of $m$ by $\ann_A(m)=\set{a\in A}[am=0]$.
Then we have that
$$ \supp m = \vof(\ann_A(m)) . $$
Indeed $m_\p=0$ iff there is a $a\notin\p$ such that $am=0$, i.e.\ iff $\ann_A(m)$ is not a subset of $\p$.
Thus $\p\notin\supp m$ iff $\p\notin\vof(\ann_A(m))$.

Recall that we have
$$ \supp M = \set{\p\in\spec A}[M_\p\neq0] = \bigcup_{m\in M}\supp m . $$
If $M$ is a principal module generated by $m\in M$ then
$$ \supp M = \supp Am = \supp m = \vof(\ann m) . $$
Thus if $M$ is finitely generated by $m_1,\dots,m_n$ we have that
$$ \supp M = \bigcup_{i=1}^n\supp m_i = \bigcup_{i=1}^n\vof(\ann m_i) $$
so for a finitely-generated $M$, $\supp M\subseteq\spec A$ is closed.

Recall that we extended these concepts to $\O_X$-modules.
For an $\O_X$-module $\F$ and a global section $s\in\Gamma(X,\F)$ we have
$$ \supp s = \set{p\in X}[s_p\neq0\hbox{ in $\F_p$}],\qquad \supp\F = \set{p\in X}[\F_p\neq0] = \bigcup_{s\in\Gamma(X,\F)}\supp s . $$
In particular $\supp\tilde M=\supp M$.

Supports behave well in exact sequences: if $0\to M'\to M\to M''\to0$ is exact then $\supp M=\supp M'\cup\supp M''$.
We can extend this to $\O_X$-modules: if $0\to\F'\to\F\to\F''\to0$ is exact then $\supp\F=\supp\F'\cup\supp\F''$.
The proof boils down to the fact that if $0\to A\to B\to C\to0$ is exact, then $B=0$ iff $A=C=0$.
Then because taking stalks is exact, $0\to\F'_p\to\F_p\to\F''_p\to0$ is exact.
Then $p\notin\supp\F$ iff $\F_p=0$ iff $\F'_p=\F''_p=0$ as desired.

\bprop[name={suppses}]

    If $0\to\F'\to\F\to\F''\to0$ is a short exact sequence of $\O_X$-modules, then
    $$ \supp\F = \supp\F'\cup\supp\F'' . $$

\eprop

\bexam

    $\supp\F$ need not be closed in general.
    Indeed take $A=\bZ$ and $M=\bigoplus_{p\hbox{ prime}}\bZ/(p)$.
    Then for $p$ prime we know that $(\bZ/(p))_{(p)}=\bZ/(p)$ because $\bZ/(p)$ is a field and the localizing set $\bZ-(p)$ maps to the nonzero elements of $\bZ/(p)$.
    But $(\bZ/(p))_{(0)}=0$ because the localizing set $\bZ-0$ is mapped to all of $\bZ/(p)$, including zero.

    Thus
    $$ \supp M = \set{(p)}[p\in\bZ\hbox{ prime}] , $$
    which is not closed (because its associated ideal $\idof(\supp M)=0$ which has vanishing set all of $\spec\bZ$).

\eexam

If $M$ is finitely generated, and $x\in A$ has value zero at all the points in $\supp M$ (i.e.\ lies in all the prime ideals in $\supp M$), then there is a power $x^n$ which
annihilates $M$.
Indeed if $m_1,\dots,m_n$ generate $M$ then $\supp M=\bigcup_i\vof(\ann m_i)$.
Thus $x$ lies in all of the primes containing $\ann m_i$, thus $x\in\sqrt{\ann m_i}$.
Then $x^{n_i}\in\ann m_i$, and by taking the maximum $n=n_i$ we have $x^n\in\ann m_i$ and so $x^n\in\ann M$.

Also if $M$ is finitely generated an $x\in A$, then $\supp(M/xM)=\supp M\cap\vof(x)$.
Firstly $(xM)_\p=x_\p M_\p$, because $xM$ is the image of $M\xtos{\times x}M$, localization commutes with images, and the localization of $\times x$ is $\times x_\p$.
Thus $\p\notin\supp(M/xM)$ iff $x_\p M_\p=M_\p$, i.e.\ iff $x_\p$ acts surjectively on $M_\p$.
If $\p\notin\supp M$ then $M_\p=0$ so this is clear, and if $\p\notin\vof(x)$ then $x\notin\p$ so $x_\p$ is a unit and so $\supp(M/xM)\subseteq\supp M\cap\vof(x)$.
Now conversely suppose $\p\notin\supp(M/xM)$ and $\p\in\vof(x)$, so $x\in\p$; we want to show that $\p\notin\supp M$, i.e.\ that $M_\p=0$.

So in our case we have a finitely generated $A_\p$-module $M_\p$ and a non-unit $x_\p$ which acts surjectively on $M_\p$.
By Nakayama's lemma this means $M_\p=0$.
Indeed we can rephrase our situation as having a local ring $(A,\m)$ ($=(A_\p,\p A_\p)$) and a finitely-generated module $M$ ($=M_\p$) such that a non-unit
$x\in A$ ($=x_\p$) acts surjectively on $M$.
Because $x\in\m$ this means that $\m M=0$.
As $M$ is finitely generated, this means that $M$ must be zero by Nakayama.

\bdefn

    Let $M$ be an $A$-module.
    Its {\emphcolor associated prime ideals} (or {\emphcolor associated points}, if we are taking a geometric viewpoint) are those {\it prime\/} ideals of $A$ which are of the
    form $\ann_A(m)$ for $m\in M$.
    The set of associated points of $M$ is denoted $\ass M\subseteq\spec A$.

    The associated points/prime ideals of $A$ are its associated points viewed as a module ovr itself.

\edefn

If $A$ is a domain then $\ann_A(a)=0$ for all $a\in A$, which is prime, so $\ass(A)=\set0$.

\blemm

    Let $M'\subseteq M$ be $A$-modules, then
    \benum
        \item $\p\in\ass M$ iff there is an injection $A/\p\inj M$,
        \item $\ass M'\subseteq\ass M$,
        \item $\ass M\subseteq\supp M$.
    \eenum

\elemm

\bproof

    If there is an injection $\phi\colon A/\p\inj M$ then
    $$ a\in\ann_A(\phi1) \iff a\phi(1) = 0 \iff \phi(a) = 0 \iff a\in\p $$
    so that $\ann_A(\phi1)=\p$, so $\p$ is an associated point of $M$.
    Conversely if $\p=\ann_A(m)$ is associated then $A\to M$ given by $a\mapsto am$ has kernel $\p$, giving rise to the desired injection.

    (2) follows from (1) as if $\p\in\ass M'$ then the injection $A/\p\inj M'$ composes with inclusion to give an injection $A/\p\inj M$.

    For (3) if $\p\in\ass M$ then there is an injection $A/\p\inj M$.
    Because localization is exact and thus preserves monomorphisms, this gives rise to an injection $(A/\p)_\p\inj M_\p$.
    And $(A/\p)_\p=A_\p/\p A_\p=\kappa(\p)$ is nonzero, so $M_\p$ is nonzero, meaning $\p\in\supp M$ as desired.
    \qed

\eproof

A simpler proof of (3) is just that $\ann_A(m)$ is independent of if we view $m\in M'$ or $m\in M$.

\blemm

    Suppose $A$ is Noetherian, and $m\in M$ is nonzero.
    Then there is a multiple $n=xm$ such that for any nonzero $yn\neq0$, we have $\ann yn=\ann n$.

\elemm

\bproof

    In general $\ann n\subseteq\ann yn$.
    Define
    $$ \Sigma = \set{\ann xm}[xm\neq0] $$
    which is a collection of ideals of $A$, and as $A$ is Noetherian has a maximal element $\ann xm$.
    Then for any $y$, $\ann yxm\subseteq\ann xm$ and thus there is equality.
    \qed

\eproof

In this case $\ann n$ is prime.
Indeed if $ab\in\ann n$ then $abn=0$.
So either $bn=0$, so $b\in\ann n$, or $a\in\ann bn=\ann n$.
Thus we have proven the following.

\bprop[name={assprimenoether}]

    If $M$ is a nonzero module over a Noetherian ring $A$, then $\ass_AM$ is nonempty.
    Furthermore, for any nonzero $m\in M$, there is an associated prime $\p$ containing $\ann m$ and $\p=\ann xm$ for some $x\in A$.

\eprop

\bprop[name={natinjasspt}]

    Suppose $M$ is a nonzero module over a Noetherian ring $A$.
    Then the natural map
    $$ M \inj \prod_{\p\in\ass M}M_\p $$
    is an injection.

\eprop

\bproof

    Let $K$ denote the kernel, and suppose it is nonzero.
    Then by the above proposition it has an associated prime $\p$ which by monotonicity is an associated prime of $M$.
    It is the annihilator of $m\in K\subseteq M$, but because $m$ is in the kernel of the map, $m_\p=0$.
    Thus there is an $a\notin\p$ such that $am=0$, contradicting the fact that $\ann_A(m)=\p$.
    \qed

\eproof

In the above injection we may restrict the $\p$ to be those associated primes which are maximal amongst the associated primes.

\bprop[name={asszerodiv}]

    Let $A$ be Noetherian and $f\in A$.
    Then $f$ is a zerodivisor on $M$ iff $f$ vanishes at an associated point of $M$.
    In other words $\bigcup\ass M$ is the set of zerodivisors of $M$.

\eprop

\bproof

    If $f$ vanishes at $\p\in\ass M$ then $f\in\p=\ann m$ so $fm=0$, meaning $f$ is a zerodivisor.

    Now suppose that $f$ vanishes at no associated point, and consider the commutative square

    \diagram{
        M&\prod_{\p\in\ass M}M_\p\cr
        M&\prod_{\p\in\ass M}M_\p
    }{
        \diagarrow{from={1,1}, to={1,2}, left cap={(}}
        \diagarrow{from={2,1}, to={2,2}, left cap={(}}
        \diagarrow{from={1,1}, to={2,1}, text={\times f}, x distance=-.25cm}
        \diagarrow{from={1,2}, to={2,2}, text={\times f}, x distance=.25cm}
    }

    Note that multiplication $M_\p\xtos{\times f}M_\p$ is injective.
    By assumption $f\notin\p$, so it is a unit of $A_\p$.
    Thus the right vertical arrow is injective, and thus so too must be the left.
    \qed

\eproof

A quicker proof of the converse in the above proof is that if $M\xtos{\times f}M$ is not injective then it has a nonzero kernel $K$.
Then it has an associated point $\p=\ann_A(m)$ for $m\in K$.
This is also an associated point of $M$, and $fm=0$ implies that $f\in\p$, a contradiction.

Note that $\ass(A/\p)=\set\p$ for $\p\leq A$ prime.
This is because for any nonzero $a\in A/\p$, $x\in\ann(a)$ iff $xa\in\p$ iff $x\in\p$ (because $a\notin\p$), so $\ann(a)=\p$.

\bprop[name={assses}]

    Suppose
    $$ 0 \to M' \to M \to M'' \to 0 $$
    is a short exact sequence of $A$-modules.
    Then
    $$ \ass M' \subseteq \ass M \subseteq \ass M' \cup \ass M'' . $$

\eprop

\bproof

    The first inclusion was already proven.
    Now suppose $\p=\ann m\in\ass M$.
    We want to find a submodule of $M'$ or $M''$ isomorphic to $A/\p$.
    Consider the sub-short exact sequence
    $$ 0 \to Am\cap M' \to Am \to Am/(Am\cap M') \to 0 . $$
    It is sufficient to prove the proposition for this short exact sequence, as $\p\in\ass Am$, and $\ass(Am\cap M')\subseteq\ass M'$, $\ass(Am/(Am\cap M'))\subseteq\ass(M'')$.
    Thus it is sufficient to prove the proposition in the case
    $$ 0 \to I/\p \to A/\p \to A/I \to 0 . $$

    So we want to show that $\p$ is an associated point of either $I/\p$ or $A/I$.
    If $I/\p\neq0$ then choose a nonzero element $a\in I/\p$, and as it is an element of $A/\p$ we have $\ann(a)=\p$ as desired.
    Otherwise $\p=I$ in which case $A/I=A/\p$ so clearly $\p$ is an associated point.
    \qed

\eproof

\bexam

    The inclusions above may be strict, in particular $\ass M$ may be a proper subset of $\ass M'\cup\ass M''$.

    Recall that for an integral domain $A$, $\ass(A)=\set{0}$.
    Consider then the short exact sequence
    $$ 0 \to \bZ \xtos{\times2}\bZ \to \bZ/2 \to 0 . $$
    We have that $\ass(\bZ/2)=\set{(2)}$ which is not contained in $\ass(\bZ)$.

\eexam

In a similar vein we have the following result.

\bprop[name={asssuppses}]

    Suppose $A$ is Noetherian and we have a short exact sequence of $A$-modules
    $$ 0 \to M' \to M \to M'' \to 0 . $$
    Suppose $\p\in\ass M''$ but $\p\notin\supp M'$.
    Then $\p\in\ass M$.

\eprop

\bproof

    Let $m''\in M''$ with $\p=\ann(m'')$.
    Then choose a lift $m\in M$ of $m''$, and consider the inclusion of short exact sequences

    \diagram{
        0&\ker(Am\to Am'')&Am&Am''&0\cr
        0&M'&M&M''&0
    }{
        \diagarrow{from={1,1}, to={1,2}}
        \diagarrow{from={1,2}, to={1,3}}
        \diagarrow{from={1,3}, to={1,4}}
        \diagarrow{from={1,4}, to={1,5}}
        \diagarrow{from={2,1}, to={2,2}}
        \diagarrow{from={2,2}, to={2,3}}
        \diagarrow{from={2,3}, to={2,4}}
        \diagarrow{from={2,4}, to={2,5}}
        \diagarrow{from={1,2}, to={2,2}, left cap={(}}
        \diagarrow{from={1,3}, to={2,3}, left cap={(}}
        \diagarrow{from={1,4}, to={2,4}, left cap={(}}
    }

    Note that indeed $\ker(Am\to Am'')\subseteq M'$ because if $am=0$ in $M''$, then $am\in M'$ as $M'=\ker(M\to M'')$.
    Thus we have
    $$ \supp\ker(Am\to Am'') \subseteq \supp M',\qquad \ass(Am) \subseteq \ass M,\qquad \ass(Am'') \subseteq \ass(M'') , $$
    and so we can consider the top row.
    That is, we can consider a short exact sequence of the form
    $$ 0 \to \p/I \to A/I \to A/\p \to 0 , $$
    and the hypothesis is $\p\notin\supp(\p/I)$.

    Define $B=A/I$ so that $\q=\p/I$ is a prime ideal of $B$ and our short exact sequence is
    $$ 0 \to \q \to B \to B/\q \to 0 . $$
    And because localizing at $\p$ is the same as localizing at $\q$ (for $B$-modules), this means that $\q\notin\supp\q$.

    Because $A$ is Noetherian, $\q$ is finitely generated, and so $\supp\q$ is closed.
    Note that $\p\notin\vof(I)$ implies $\bigcap\vof(I)=\sqrt I$ is not a subset of $\p$, as this would imply $\p\in\vof(\p)\subseteq\vof(I)$.
    Thus there is a $b\in\bigcap\supp\q$ but $b\notin\q$.

    From the former we must have that $b^n$ annihilates $\q$ for some $n\geq0$.
    This is because if $\q=(x_1,\dots,x_n)$ then $\supp\q=\vof(\ann(x_1)\cdots\ann(x_n))$ and so $b^n\in\ann(x_1)\cdots\ann(x_n)\subseteq\ann(\q)$ for some $n$.
    But from the latter $b^n\notin\q$.

    Thus $\q\subseteq\ann(b^n)$ (because $b^n$ annihilating $\q$ is the same as $\q$ annihilating $b^n$), but because $b^n\notin\q$ we have $\ann(b^n)\subseteq\q$.
    This is since if $xb^n=0\in\q$ then we must have $x\in\q$.
    Thus $\q=\ann_B(b^n)$ is an associated prime of $B$, viewed as a $B$-module.
    Viewed as an $A$-module, $\p=\ann_A(b^n)$ because $ab^n=0$ iff $a+I\in\ann_B(b^n)=\q$ iff $a\in\p$.
    \qed

\eproof

\blemm

    Suppose $M$ is a finitely generated module over a Noetherian ring $A$.
    Then $M$ has a finite filtration
    $$ 0 = M_0 \subsetneq M_1 \subsetneq \cdots \subsetneq M_n = M $$
    where the quotients are all of the form $M_{i+1}/M_i\cong A/\p_i$ for $\p_i\leq A$ a prime.

\elemm

\bproof

    From the hypotheses on $M$ we conclude it is Noetherian itself.
    Furthermore by \refmath[proposition]{assprimenoether} there is a prime $\p_0\leq A$ such that $A/\p_0$ embeds into $M$, so define $M_1=A/\p_0$.
    Now suppose that inductively we've defined $M_0,\dots,M_n$.
    If $M_n\neq M$, then $M/M_n$ is a Noetherian $A$-module so we can embed $A/\p_n\inj M/M_n$.
    This corresponds to a submodule $M_n\subsetneq M_{n+1}\subseteq M$ with quotient $M_{n+1}/M_n\cong A/\p_n$.

    Because $M$ is Noetherian and this chain is increasing, it must terminate at some point, i.e.\ $M_n=M$.
    \qed

\eproof

\blemm

    Suppose $M$ is an $A$-module with a filtration as in the previous lemma.
    Then every associated prime of $M$ is one of the $\p_i$s.
    Similarly
    $$ \supp M = \bigcup_i\vof(\p_i) . $$

\elemm

\bproof

    We inductively show that $\ass M_i\subseteq\set{\p_0,\dots,\p_{i-1}}$.
    For $M_0=0$ this is clear, and then for $M_{i+1}$ we have a short exact sequence
    $$ 0 \to M_i \to M_{i+1} \to M_{i+1}/M_i = A/\p_i \to 0 . $$
    By \refmath[proposition]{assses} we have
    $$ \ass M_{i+1} \subseteq \ass M_i \cup \ass A/\p_i \subseteq \set{\p_0,\dots,\p_{i-1}} \cup \set{\p_i} $$
    as desired.

    For the second claim we follow essentially the same proof: inductively we show $\supp M_i=\vof(\p_0)\cup\cdots\cup\vof(\p_{i-1})$
    using \refmath[proposition]{suppses}.
    \qed

\eproof

\bcoro

    A finitely generated module over a Noetherian ring has finitely many associated points.

\ecoro

\blemm

    Suppose $M$ is finitely generated over a Noetherian $A$.
    Then suppose $\p\leq A$ is a prime ideal corresponding to an irreducible component of $\supp M\subseteq\spec A$.
    Then $\p$ is an associated point of $M$.

\elemm

\bnote

    $\supp M$ is closed in $\spec A$, so its closed irreducible subsets are of the form $\vof(\p)$ for a prime ideal $\p\leq A$.

\enote

\bproof

    Let $M_i$ be the filtration from the previous lemma with $M_{i+1}/M_i\cong A/\p_i$.
    So by the previous lemma $\supp M=\bigcup_i\vof(\p_i)$, and in general $\supp M_n=\bigcup_{i<n}\vof(\p_i)$.
    The irreducible components of $\supp M$ are then of the form $\vof(\p_i)$ where $\p_i$ is minimal amongst the $\p_j$s (as it is then minimal in $\supp M$).

    So if $\p_i$ is minimal amongst the $\p_j$s, suppose further that $\p_i$ is its first occurance.
    Thus we have a short exact sequence
    $$ 0 \to M_i \to M_{i+1} \to M_{i+1}/M_i = A/\p_i \to 0 . $$
    Then we have $\p_i\in\ass(A/\p_i)$ and $\p_i\notin\supp M_i$ as $\supp M_i=\vof(\p_0)\cup\cdots\cup\vof(\p_{i-1})$ and none of the $\p_0,\dots,\p_{i-1}$ are contained in $\p_i$ (it is minimal).
    So by \refmath[proposition]{asssuppses} $\p_i\in\ass M_{i+1}\subseteq\ass M$ as desired.
    \qed

\eproof

Recall that by \refmath[proposition]{asszerodiv}, $f\in A$ is a zero divisor of $M$ iff it vanishes at some associated point.
Because $\supp A=\spec A$, by the previous lemma we see that for Noetherian $A$, $f\in A$ is a zerodivisor iff it lies in some minimal prime ideal of $A$.

One direction of this holds true without assuming Noetherian-ness.
If $f\in A$ lies in a minimal prime, it is a zero divisor.
Indeed suppose $f\in\p$ is minimal, then by minimality $\p A_\p$ is the unique prime ideal of $A_\p$, and thus $f\in A_\p$ is nilpotent.
Thus there is an $x\in A-\p$ such that $xf^n=0$, i.e.\ $f$ is a zero-divisor.

\bprop

    If $M$ is finitely generated over a Noetherian $A$, then $\supp M=\cl{\ass M}$.

\eprop

\bproof

    As $\ass M\subseteq\supp M$ and $\supp M$ is closed, we have one direction of inclusion.
    Now if $\p\in\supp M$, then it lies in some irreducible component of $\supp M$, say $\p\in\vof(\q)=\cl\q$.
    Then $\q$ is an associated point of $M$ by the above lemma, so $\q\in\ass M$ and $\p\in\cl\q\subseteq\cl{\ass M}$.
    \qed

\eproof

Recall that radicals commute with localization, so $\nil(A)_\p\cong\nil(A_\p)$.
Thus $\nil(A)_\p\neq0$ iff $A_\p$ is nonreduced.
In other words $\supp\nil(A)$ is the locus of points $\p$ where $A_\p$ is nonreduced.

Now if $A$ is Noetherian, $\p\in\ass A$ iff there is a $f\in A$ such that $\supp f=\vof(\p)$.
For one direction recall that $\supp f=\vof(\ann f)$.
So if $\p=\ann f$ is associated this is immediate.
Conversely if $\supp f=\vof(\p)$ then $\p$ corresponds to an irreducible component of $\supp Af=\supp f$, which is finitely generated.
Thus $\p\in\ass Af\subseteq\ass A$ as desired.

Recall that if $A$ is Noetherian and $M$ finitely generated, there is a filtration
$$ 0 = M_0 \subsetneq \cdots \subsetneq M_n = M,\qquad \frac{M_{i+1}}{M_i} = \frac A{\p_i} , $$
and $\ass M$ are among the $\p_i$.
But it is not necessarily the case that each $\p_i$ is associated.
But what is true is that each $\p_i$ {\it contains\/} an associated prime.

Indeed, $\supp(A/\p_i)=\vof(\p_i)\subseteq\supp M$ (recall $\supp M$ is the union of these vanishing sets).
As $\vof(\p_i)=\cl{\p_i}$ is irreducible, it is contained in an irreducible component of $\supp M$.
So $\vof(\p_i)\subseteq\vof(\p)$ which is irreducible, and thus $\p$ is an associated point of $M$, and $\p_i\leq\p$.

\bprop[name={supploc}]

    If $M$ is an $A$-module and $S\subseteq A$ multiplicative then
    $$ \supp_{S^{-1}A}S^{-1}M = \supp_AM\cap\spec S^{-1}A $$
    where we view $\spec S^{-1}A$ as a subset of $\spec A$.

\eprop

\bproof

    For a prime ideal $S^{-1}\p\leq S^{-1}A$ note that $\p\cap S=\emptyset$ meaning $S\subseteq A-\p$.
    Localizing at $S^{-1}\p$ means localizing by $S^{-1}A-S^{-1}\p$, and because we can focus on non-units, this is equivalent to localizing by
    $(S^{-1}A-S^{-1}\p)\cap A$.
    Now $a\in S^{-1}A\cap A$ is in $S^{-1}\p$ iff $a\in\p$: if $a=p/s$ for $p\in\p,s\in S$, then $tsa=tp$ for $t\in S$, so $tsa\in\p$ and $ts\notin\p$ so $a\in\p$.
    Thus $(S^{-1}A-S^{-1}\p)\cap A=A-\p$.

    Thus localizing by $S$ and then at $S^{-1}\p$ is the same as localizing at $\p$.
    And so
    $$ S^{-1}\p \in \supp_{S^{-1}A}S^{-1}M \iff (S^{-1}M)_{S^{-1}\p} = M_\p \neq 0 \iff \p \in \supp_AM $$
    giving the desired result.
    \qed

\eproof

\bprop[name={assloc}]

    Let $M$ be a finitely generated module over a Noetherian ring $A$.
    Then for a multiplicative $S\subseteq A$,
    $$ \ass_{S^{-1}A}S^{-1}M = \ass_AM\cap\spec S^{-1}A . $$

\eprop

\bproof

    First suppose $\p\in\spec S^{-1}A\cap\ass_AM$, then there is an injection $A/\p\inj M$.
    Localization preserves injections and so we have an injection $S^{-1}(A/\p)=S^{-1}A/S^{-1}\p\inj S^{-1}M$.
    Because $S^{-1}\p$ is prime, we have $\p\in\ass_{S^{-1}A}S^{-1}M$.

    Now suppose $\q=S^{-1}\p\in\ass_{S^{-1}A}S^{-1}M$ so $\q=\ann_{S^{-1}A}(m/s)$ for $m\in M$ and $s\in S$.
    Because $s\in S$ is a unit, we have $\q=\ann_{S^{-1}A}(m)$.
    Thus $\supp_{S^{-1}A}m=\vof_{S^{-1}A}(\q)$, and by the previous proposition
    $$ \supp_{S^{-1}A}m = \supp_Am \cap \spec S^{-1}A,\qquad \vof_{S^{-1}A}(\q) = \vof(\p)\cap\spec S^{-1}A . $$
    Thus $\p\in\supp_Am$, and it is minimally so: if $\p'\in\supp_Am$ and $\p'\leq\p$ then $S^{-1}\p'\leq \q$ and $S^{-1}\p'\in\supp_{S^{-1}A}m$.
    Thus $\ann_{S^{-1}A}(m)=\q\leq S^{-1}\p'$ so that $S^{-1}\p'=\q$ and thus $\p'=\p$.
    So $\p$ is corresponds to an irreducible component of $\supp_Am$ and thus is an associated prime of $Am$, and thus of $M$.
    \qed

\eproof

\bdefn

    The associated points of $M$ which are {\it not\/} the generic points of irreducible components of $\supp M$ are called {\emphcolor embedded points} or {\emphcolor embedded primes}.

\edefn

If $A$ is reduced, then $A$ has no embedded primes.
Suppose that $\p=\ann a$ is an embedded prime, so $\p$ is not minimal.
Let $\q$ be a minimal prime, so there is a $b\in\p-\q$, then $ab=0$ and thus $a\in\q$.
So $a$ lies in all minimal primes, and since every prime contains a minimal prime, $a$ lies in all primes.
Thus $a$ is nilpotent, but $A$ is reduced so $a=0$ a contradiction.

It is not true that nonreduced rings have embedded primes.
For instance $k[x]/(x^2)$ has no embedded primes: its only prime is $(x)=\ann x$, and is thus minimal.

But if $\p$ is an embedded prime of $A$, then $A_\p$ is nonreduced.
Indeed, suppose $\p=\ann(a)$, then $\p$ is not minimal so there are primes $\q<\p$.
These form the non-maximal prime ideals of $A_\p$.
And as before $a\in\q$ for all of them, so $a$ is in the intersection of all the prime ideals of $A_\p$.

\bdefn

    Let $\F$ be a coherent sheaf on a locally Noetherian scheme $X$.
    Then $\F$'s {\emphcolor associated points} are the points $p\in X$ which lie in an affine subscheme $p\in\spec A\subseteq X$
    such that $p$ is an associated point of $\Gamma(\spec A,\F)\in\Mod_A$.

\edefn

Recall that for a Noetherian $A$, $\p\leq A$ is an associated point of $M$ iff $\vof(\p)$ is an irreducible component of $\supp m$ for some $m\in M$.
Indeed if $\p=\ann m$ then $\vof(\ann m)=\supp m$.
Conversely if $\vof(\p)$ is an irreducible component of $\supp m$, then it is an irreducible component of $\supp Am$ which is finitely generated and thus $\p$
is an associated prime of $Am\subseteq M$.

So for $A$ Noetherian and $M$ an $A$-module, a prime $\p\leq A$, the following are equivalent:
\benum
    \item $\p$ is associated,
    \item $\vof(\p)=\supp m$ for some $m\in M$,
    \item $\vof(\p)$ is an irreducible component of $\supp m$ for some $m\in M$.
\eenum

Thus if $X$ is a locally Noetherian scheme and $\F$ a coherent sheaf, then for $p\in X$ the following are equivalent:
\benum
    \item $p$ is associated,
    \item $\cl p=\supp s$ for some local section $s\in\Gamma(U,\F)$,
    \item $\cl p$ is an irreducible component of $\supp s$ for some local section $s\in\Gamma(U,\F)$.
\eenum
Indeed by the previous equivalence clearly (1) implies (2) implies (3).
Now if $\cl p$ is an irreducible component of $\supp s$ for $s\in\Gamma(U,\F)$, let $\spec A\subseteq U$ be an open affine subset.
Then $\supp s\cap\spec A=\supp s|_{\spec A}$, and $\cl p\cap\spec A$ remains an irreducible component of $\supp s\cap\spec A=\supp s|_{\spec A}$.
So by the previous equivalence (3) implies (1).

If $X$ is locally Noetherian, $\F$ coherent, and $U\subseteq X$ is open, then
$$ \Gamma(U,\F) \to \prod_{p\in\ass\F\cap U}\F_p $$
is injective.
Indeed, this is true for any affine subscheme $\spec A\subseteq U$ by \refmath[proposition]{natinjasspt}.
So any section in the kernel of this map is in the kernel of all the maps for affine subschemes, which cover $U$, and thus the section must be zero.

\bdefn

    An open subscheme $U\subseteq X$ is {\emphcolor scheme-theoretically dense} if a section of $V\subseteq X$ is zero when it restricts to zero on $U\cap V$.

\edefn

Note that if $U\subseteq X$ is scheme-theoretically dense, then it is topologically dense.
This is because a scheme-theoretically dense subset intersects all open subsets of $X$.
If $U\cap V=\emptyset$ then $\O_X(V)$ is the zero ring, and thus $V$ cannot contain any affine subschemes, so $V=\emptyset$.

If $X$ is locally Noetherian, $U\subseteq X$ is scheme-theoretically dense iff it contains all of $X$'s associated points.
Suppose that $U$ contains all of $X$'s associated points, and let $\spec A\subseteq X$ be affine open.
There is an injection
$$ A \inj \prod_{p\in\ass A}A_p , $$
and because $U$ contains all of $A$'s associated points, so too does $U\cap\spec A$, and thus in the injection above $f$ maps to zero, so $f=0$.

Conversely suppose $U$ doesn't contain an associated point $p$.
Then $p\in\spec A\subseteq X$ corresponds to $p=\ann f$ for nonzero $f\in A$.
Now let $q\in U\cap\spec A$, then $p$ is not contained in $q$ as if it were then $p\leq q$ so that $q\in\cl p$ but $p\notin U$ is open.
Because $p$ is not contained in $q$, there is an $x\in p-q$, and so $x$ becomes a unit in $A_q$.
Because $x\in\ann f$, this means that $f$ is equal to $0$ in $A_q$ (as $xf=0$ and $x$ is a unit), so $f\in q$ for all $q\in U\cap\spec A$.
Thus $f|_{U\cap\spec A}=0$ but $f|_{\spec A}\neq0$.

Note that the collection of scheme-theoretically dense open subsets of a scheme $X$ is cofiltered: if $U,V$ are scheme-theoretically dense then so too is $U\cap V$.

\bdefn

    Let $X$ be a scheme.
    We define the {\emphcolor total fraction ring} to be the filtered colimit over the scheme-theoretically dense subsets of $X$:
    $$ \colim_{U\subseteq X\text{ dense}}\O_X(U) . $$
    An {\emphcolor rational function} is an element of the total fraction ring, equivalently a section over a scheme-theoretically dense open subset of $X$.

\edefn

Note that if $f\in\O_X(U)$ and $g\in\O_X(V)$ are rational functions, then $f=g$ (as rational functions) iff $f|_{U\cap V}=g|_{U\cap V}$.
Clearly this is sufficient, but it is also necessary: if $f|_W=g|_W$ for $W\subseteq U\cap V$, then $f-g=0$ on $W$ which is scheme-theoretically dense, so $f-g=0$ on $U\cap V$.

Thus we see that any rational function $f$ has a {\emphcolor domain of definition}: a maximally open dense $U\subseteq X$ for which $f$ is a section.
This is because if we let $(U_i,f_i)$ be all the rational functions equal to $f$, then by the previous paragraph, the $f_i$ agree on intersections.
Thus we can glue the $f_i$ to get a section of $U=\bigcup_iU_i$.
We say that a rational function $f$ is {\emphcolor regular} at a point $p\in X$ if $p$ lies in $f$'s domain of definition.

Note that if $X$ is integral, then all of its non-empty open subsets are scheme-theoretically dense.
Indeed, let $\eta$ be its generic point so $\O_{X,\eta}=K(X)$.
Then by \refmath[proposition]{intschinjmaps}, all of the canonical maps $\O_X(U)\to K(X)$, $f\mapsto f_\eta$, are injective.
So $f=0$ iff $f_\eta=0$, thus if $f\in\O_X(U)$ is zero in $U\cap V$, it is zero in $U$.
In particular the total fraction ring of an integral scheme is its fraction field.
