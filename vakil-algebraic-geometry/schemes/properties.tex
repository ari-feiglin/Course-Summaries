\subsection{Properties of schemes}

\subsubsection{Topological properties}

\bprop

    If $X$ is a topological space with a finite open cover $\set{X_i}_{i=1}^n$ such that each $X_i$ is irreducible and $\bigcap_iX_i\neq\emptyset$,
    then $X$ is irreducible.

\eprop

\bproof

    Let $Y=\bigcap_iX_i$; as a finite intersection of open sets it is open.
    For $U,V\subseteq X$ nonempty open, we must have that $U\cap X_i\neq\emptyset$ for some $i$.
    Since $X_i$ is irreducible and $Y\subseteq X_i$ is open, we must have that $U\cap Y$ is nonempty.
    Similarly $V\cap Y$ is nonempty, and these are both nonempty open subsets of any $X_i$, so they have nonempty intersection.
    Thus $U\cap V\neq\emptyset$ as desired.
    \qed

\eproof

\bcoro

    If $A$ is a domain, then $\bP^n_A$ is irreducible.

\ecoro

\bproof

    We know that $\dof_+(x_i)\cong\spec A[x_0,\dots,x_n]$ is irreducible by \refmath[corollary]{domspecirred}.
    And the intersection of all these $\dof_+(x_i)$ is nonempty (it contains the zero ideal).
    \qed

\eproof

Recall that for an affine scheme, there is a bijection between points and irreducible closed subsets, given by $p\mapsto\cl{\set p}$.
Recall this is because closed irreducible subsets are all of the form $\vof(\p)$ for a prime ideal $\p$.
This is true for schemes in general.
Indeed, if $p\mapsto\set p$ is a bijection between points and closed irreducible subsets of $X_i\subseteq X$ for an open cover $X=\bigcup_iX_i$, then
it is one for $X$ as well.

Let $Z\subseteq X$ be closed irreducible, so there is an $i$ such that $Z\cap X_i\subseteq X_i$ is nonempty.
Thus there is $p\in X_i$ such that $Z\cap X_i=\clos_{X_i}(p)$.
Because $Z\cap X_i\subseteq Z$ is open, it is dense, so that
$$ \clos_X(p) = \clos_X(\clos_{X_i}(p)) = \clos_X(Z\cap X_i) = Z $$
as desired.

Now if $\clos(p)=\clos(q)=Z$ then $p=q$.
Indeed, because $\set p,\set q$ are dense in $Z$, they intersect all of its nonempty open subsets.
So choose $i$ such that $Z\cap X_i\neq\emptyset$, then $p,q\in X_i$ and $\clos_{X_i}(p)=\clos_{X_i}(q)=Z\cap X_i$ and then by assumption $p=q$.

\bcoro[name={schemesober}]

    If $X$ is a scheme, $p\mapsto\set p$ is a bijection between points of $X$ and its closed irreducible subsets.

\ecoro

\bproof

    $X$ has an open cover of affine schemes, which have this property.
    By the above discussion, $X$ has this property.
    \qed

\eproof

\bnote

    A space with this property is called a {\emphcolor Sober space}.

\enote

\bprop

    If $X=\bigcup_iX_i$ is a finite covering of $X$ by Noetherian subspaces, then $X$ is Noetherian.

\eprop

\bproof

    Let $Z_0\supset Z_1\supset\cdots$ be a descending chain of closed subsets of $X$.
    Then intersecting with $X_i$ gives a stabilizing chain, say it stabilizes at $n_i$.
    Then the original chain stabilizes at $N=\max n_i$ (because the original chain is the union of the intersection with the $X_i$s).
    \qed

\eproof

\bcoro

    If $X$ is a scheme with a finite cover $X=\bigcup_{i=1}^n\spec A_i$ where each $A_i$ is Noetherian, then $X$ is a Noetherian space.

\ecoro

\bcoro

    If $A$ is Noetherian, then $\bP^n_A$ is.

\ecoro

\bproof

    We know that $A[x_0,\dots,x_n]$ is Noetherian by Hilbert's basis theorem, and $\bP^n_A$ has a finite covering of the spectrum of this
    algebra.
    \qed

\eproof

Note that if $X$ has a finite covering by quasicompact open subsets, then $X$ is quasicompact.
This is pretty immediate by taking an open cover and then considering it over each open set.
Thus the following is immediate (as affine schemes are quasicompact).

\bcoro

    A scheme is quasicompact iff it has a finite open affine covering.

\ecoro

\bprop

    Let $X$ be a quasicompact scheme, then every closed subset of $X$ has a closed point.

\eprop

\bproof

    For affine schemes this is true, because every ideal $I\leq A$ is contained in a maximal ideal, which is a closed point in $\vof(I)$.

    Now let $X=\bigcup_{i=1}^nU_i$ form an affine cover, and let $p_1\in Z\cap U_1$ be a closed point.
    If $p_1$ is closed in $X$ we are done, otherwise $\cl{p_1}$ contains points other than $p_1$, which necessarily cannot lie in $U_1$.
    So $\cl{p_1}$ intersects some other $U_i$, call it $U_2$, and then again it contains some closed point (of $U_2$) $p_2\in\cl{p_1}\cap U_2$.
    If $p_2$ is closed in $X$ we are done, otherwise $\cl{p_2}\subseteq\cl{p_1}$, and by \refmath[corollary]{schemesober} this is a strict inclusion.
    Thus it intersects some other $U_3$, and we can inductively choose a closed point $p_{i+1}\in\cl{p_i}\cap U_i$.

    This process must halt eventually, as there are only $n$ affine sets, so eventually we must find a closed point.
    \qed

\eproof

\bremark

    This proposition can help us prove properties of schemes.
    Specifically suppose we have some property $P$ of schemes which is {\emphcolor open}: if a point $p$ has $P$, then there is a neighborhood of $p$, all of whose points have $P$.
    Then in order to check if all points of a quasicompact scheme have $P$, it is sufficient to check that the closed points have $P$.

    Note that $p\in\cl q$ iff $N(p)\subseteq N(q)$ (where $N(p)$ is the collection of $p$'s neighborhoods).
    Indeed if $p\notin\cl q$ then $X-\cl q$ is a neighborhood of $p$ which does not contain $q$.
    Conversely if $p\in U$ and $q\notin U$, then $\cl q\subseteq X-U$ and so $p\notin\cl q$.

    So if $P$ is open and all closed points of $X$ have $P$, then let $q\in X$.
    Choose a closed point $p\in\cl q$ so that there is a neighborhood $p\in U$ such that all points of $U$ have $P$.
    Because $N(p)\subseteq N(q)$, we have that $q\in U$ and thus $q$ has $P$.

\eremark

\bdefn

    A space $X$ is {\emphcolor quasiseparated} if the intersection of any two quasicompact open subsets is quasicompact.

\edefn

A scheme $X$ is quasiseparated iff the intersection of any two open affine subschemes is a finite union of affine open subsets.
If $X$ is quasiseparated this is clear, as affine subschemes are quasicompact, and open subsets are themselves schemes (so to be quasicompact they must have a finite affine covering).
Conversely if $U,V\subseteq X$ are quasicompact open, then they each have a finite affine covering, and their intersection then has a finite affine covering, so is quasicompact.

It is sufficient to only consider a basis of affine subschemes, and as such it is easy to see that affine schemes are quasiseparated: $\dof(f)\cap\dof(g)=\dof(fg)$.

Thus if $X$ is covered by affine subschemes, such that the intersection of any two of these affine subschemes is quasicompact.
Indeed, if $X=\bigcup_iU_i$ and $U_i\cap U_j=\bigcup_kV_{ijk}$ is a finite union of affine subschemes, then let $D_{i\ell}$ form an affine basis for $U_i$.
Then $D_{i\ell}\cap D_{j\ell'}\subseteq U_i\cap U_j=\bigcup_kV_{ijk}$, and so $D_{i\ell}\cap D_{j\ell'}\cap V_{ijk}$ is quasicompact as $V_{ijk}$ is affine and thus quasiseparated.
Thus $D_{i\ell}\cap D_{j\ell'}\cap V_{ijk}$ can be written as a finite union of affine schemes, and taking their unions, so too can $D_{i\ell}\cap D_{j\ell'}$.
Because the $D_{i\ell}$ form an affine basis of $X$, we have the desired result.

It is clear that a scheme $X$ is quasicompact and quasiseparated iff it can be covered by a finite union of affine subschemes which have quasicompact intersection.
Quasicompact and quasiseparated is often abbreviated as {\emphcolor qcqs}.

\bexam

    A {\emphcolor projective $A$-scheme} is a scheme of the form $\proj S_\bul$ where $S_0=A$ and $S_\bul$ is finitely generated over $A$.
    A projective $A$-scheme is qcqs.

    Indeed, let $S_\bul$ be generated by the homogeneous elements $(x_0,\dots,x_n)$ over $A$.
    Then
    $$ \proj S_\bul = \bigcup_{i=0}^n\dof_+(x_i) $$
    is a finite covering of affine subschemes (recall $\dof(x_i)=\spec S_\bul[1/x_i]_0$).
    Furthermore $\dof_+(x_i)\cap\dof_+(x_j)=\dof_+(x_ix_j)$ is affine as well, showing that $\proj S_\bul$ is qcqs as desired.

\eexam

\bexam

    Let $X=\spec k[x_1,x_2,\dots]$ and $U=X-[\m]$ where $\m$ is the maximal ideal $(x_1,x_2,\dots)$.
    Then let $Y$ be the scheme obtained by gluing two copies of $X$ along their common copy of $U$.
    Now both copies of $X$ in $Y$ are quasicompact (as they are affine), but their intersection is $U$ which is not quasicompact.

    Indeed we can cover $U$ as follows
    $$ U = \dof(\m) = \bigcup_{i=1}^\infty \dof(x_i) . $$
    And any finite union of $\dof(x_i)$s is not equal to $\dof(\m)$ (say because $x_{n+1}\notin\sqrt{(x_1,\dots,x_n)}$).

\eexam

\subsubsection{Reducedness and integrality}

Recall a ring $A$ is {\emphcolor reduced} if $\nil(A)=0$, i.e.\ it has no nonzero nilpotent elements.

\bdefn

    A scheme is {\emphcolor reduced} if its stalks are all reduced.

\edefn

\bprop[name={samefuncredscheme}]

    If $f,g$ are two functions on a reduced scheme which agree at all points, then $f=g$.

\eprop

\bproof

    It is sufficient to show that if $f$ is zero at all points, then $f=0$.
    That is if $f_p\in\m_p$ for all $p\in X$, then $f=0$.

    It is sufficient to consider this locally, so we first show this for $X=\spec A$.
    We have that $f_\p\in\p A_\p$, meaning $f\in\p$ for all prime $\p\in\spec A$.
    Thus $f\in\nil(A)$, and because ring morphisms preserve nilpotents ($\phi(f)^n=\phi(f^n)=0$), we have that $f_\p\in\nil(A_\p)=0$.
    Thus $f_\p=0$ in $A_\p$ for all $\p$.
    Because $A\to\prod_\p A_\p$ is injective, this means that $f=0$.

    Now if $X=\bigcup_i\spec A_i$, then by above we have $f=0$ in each $A_i$.
    By gluing this means $f=0$ over $X$.
    \qed

\eproof

\bprop[name={redschemecond}]

    A ring $A$ is reduced iff the affine scheme $\spec A$ is.
    And a scheme $X$ is reduced iff $\O_X(U)$ is reduced for all open $U\subseteq X$.
    It is sufficient to check this for an affine open cover $X=\bigcup_iU_i$.

\eprop

\bproof

    The first claim amounts to saying $A$ is reduced iff $A_\p$ is for all prime $\p$.
    By the injection $A\to\prod_\p A_\p$, if the $A_\p$ are all reduced then so is $A$.
    And if $A$ is reduced, recall that radicals commute with localization, so
    $$ \nil(A_\p) = \sqrt{0_\p} = \sqrt 0_p = \nil(A)_\p = 0_\p . $$
    Thus $A_\p$ is reduced as desired.

    Because being reduced is local, if $X$ is reduced then every open $U\subseteq X$ is reduced.
    By the injection $\O_X(U)\to\prod_{p\in U}\O_{X,p}$, we have that $\O_X(U)$ is reduced.

    Conversely if there is an affine open cover $X=\bigcup_iU_i$ where $\O_X(U_i)$ are reduced, then the $U_i$ are all reduced as they are isomorphic to
    $\spec\O_X(U_i)$, and this is reduced by the first paragraph.
    Stalks in $X$ can be taken local to a $U_i$, so we have the desired result.
    \qed

\eproof

\bexam

    $\bA^n_A$ is reduced for any domain $A$, as $A[x_1,\dots,x_n]$ is a domain and thus reduced.
    Similarly $\bP^n_A$ is reduced for any domain $A$, because it has an affine covering by $A[x_0,\dots,x_n]$ which are reduced.

\eexam

\bremark

    Suppose $X$ is a quasicompact scheme and $f$ vanishes at all points of $X$.
    Then there is an $n$ such that $f^n=0$ in $X$.

    Indeed suppose $X=\bigcup_i\spec A_i$, following the proof of \refmath[proposition]{samefuncredscheme}, we see that $f\in\nil(A_i)$ for all $i$.
    So there are $n_i$ such that $f^{n_i}=0$ in $A_i$.
    Taking $N$ to be the maximum $n_i$, we see that $f^n=0$ in all $A_i$, so by gluing $f=0$.

\eremark

\bdefn

    A nonempty scheme $X$ is {\emphcolor integral} if $\O_X(U)$ is an integral domain for all open $U\subseteq X$.

\edefn

\bprop

    A scheme is integral iff it is irreducible and reduced.

\eprop

\bproof

    If $X$ is integral, then let $U,V\subseteq X$ be nonempty open.
    If $U\cap V=\emptyset$ then $\O_X(U\sqcup V)=\O_X(U)\times\O_X(V)$ is not a domain.
    Thus $U\cap V$ is nonempty so $X$ is irreducible.
    And $X$ is reduced because $\O_X(U)$ is a domain and thus reduced for all $U$, and by \refmath[proposition]{redschemecond}.

    Conversely suppose $X$ is irreducible and reduced.
    Let $U\subseteq X$ be nonempty open, and suppose $f,g\neq0$ in $\O_X(U)$.
    Let $U_f=\set{p\in U}[f(p)\neq0]$, so that $U_f$ is nonempty by \refmath[proposition]{samefuncredscheme}.
    Because $X$ is irreducible $V=U_f\cap U_g\neq\emptyset$.
    For $p\in V$ we have that $f(p),g(p)\neq0$ and thus $(fg)(p)\neq0$.
    This means that $fg\neq0$ in $V$ and thus is nonzero in $U$ as well.
    \qed

\eproof

\bprop

    $\spec A$ is integral iff $A$ is an integral domain.

\eprop

\bproof

    Immediately by definition if $\spec A$ is integral, then $A$ is a domain.

    Conversely if $A$ is an integral domain, it is reduced.
    Furthermore $\nil A=0$ is a prime ideal, so $A$ is irreducible by \refmath[proposition]{irredaffine}.
    By the previous proposition this means $\spec A$ is integral.
    \qed

\eproof

If $X$ is an irreducible scheme, it is closed and so by \refmath[proposition]{schemesober} it has a unique generic point $\eta\in X$.
Now further suppose that $X$ is integral, and let $\spec A\subseteq X$ be an affine neighborhood.
Because $\eta$ is dense in $X$, it is in $\spec A$ and it must furthermore be a generic point there.
Thus $\eta=\nil(A)=0$ in $\spec A$, and thus because localization is local
$$ \O_{X,\eta} = A_\eta = A_0 = K(A) , $$
the fraction field of $A$.

We denote $\O_{X,\eta}$ by $K(X)$ and call it the {\emphcolor function field} of $X$; its elements are {\emphcolor rational functions}.

Note that the canonical map $\O_X(U)\to K(X)=\O_{X,\eta}$ is injective.
Indeed, if $f_\eta=0$ then $\eta\in\set{f_p=0}$ which is closed, and since $\eta$ is generic, $f$ is zero at all points of $X$.
By \refmath[proposition]{samefuncredscheme} this means $f=0$.

Now if $U\subseteq V$ are nonempty, then inclusion forms a morphism of schemes $U\inj V$.
Thus localizing at $\eta$ forms a map $\O_{V,\eta}\to\O_{U,\eta}$ such that the following diagram commutes

\diagram{
    \O_X(V)&\O_X(U)\cr
    \O_{V,\eta}&\O_{U,\eta}\cr
    K(X)&K(X)
}{
    \diagarrow{from={1,1}, to={1,2}, text={\res_{V,U}}, y distance=.25cm}
    \diagarrow{from={2,1}, to={2,2}}
    \diagarrow{from={3,1}, to={3,2}}
    \diagarrow{from={1,1}, to={2,1}}
    \diagarrow{from={1,2}, to={2,2}}
    \diagarrow{from={2,1}, to={3,1}, ds, right cap=-}
    \diagarrow{from={2,2}, to={3,2}, ds, right cap=-}
}

Because $K(X)$ is a field, the bottom horizontal arrow is injective.
Since the vertical arrows are injective, this means $\res_{V,U}$ is injective as well.
Thus we have shown the following.

\bprop

    Let $X$ be an integral scheme.
    Then the restriction maps are all injections, as well as the canonical maps $\O_X(U)\to K(X)$.

\eprop
