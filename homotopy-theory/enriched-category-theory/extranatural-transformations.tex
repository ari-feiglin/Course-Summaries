\subsection{Extranatural transformations}

\bdefn

    Let $\A,\B$ be $\V$-categories, $F\colon\A^\op\otimes\A\to\B$ a functor, and $K\in\B$.
    An $\Ob(\A)$-indexed family of maps $\beta_A\colon K\to F(A,A)$ is said to be {\emphcolor extranatural}
    if the following diagram commutes

    \commsq{\A(A,B)&\B(F(A,A),F(A,B))\cr\B(F(B,B),F(A,B))&\B(K,F(A,B))}
        {F(A,\bul)}{\B(\beta_B,\id)}{F(\bul,B)}{\B(\beta_A,\id)}

    Dually an $\Ob(\A)$-index family of maps $\gamma_A\colon F(A,A)\to K$ is {\emphcolor extranatural} if the following
    diagram commutes

    \commsq{\A(A,B)&\B(F(B,A),F(B,B))\cr\B(F(B,A),F(A,A))&\B(F(B,A),K)}
        {F(B,\bul)}{\B(\id,\gamma_A)}{F(\bul,A)}{\B(\id,\gamma_B)}

    Note that both of these diagrams exist in $\V$.

\edefn
